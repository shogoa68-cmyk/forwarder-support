## 実装側で補正した点（Design の CSS からの差）
1. **`.min-note` が表示されない**：適用中の指定に `display` が無く、既定の `display:none` が勝つ → 適用中に `display:block`。売値の欄の数字と重なったため、文言を「Min. 28.00」に短縮・小さく（「適用」は小計の状態チップ「MIN 適用」で示す）。
2. **未登録の三角が出ない**：入力欄の共通指定 `background:#fff`（stage1）が `background-image` を消す → `!important`。現行の橙の点線（`outline`）は Industry で消した。
3. **`#tab-master #backToQuoteFab`**：浮きボタンは `#tab-master` の外（`<body>` 直下）にあり当たらない → 見出しの右に専用ボタンを置き、`body:has(#tab-master.active)` で浮きボタンを隠す。
4. **`--shadow-lg`**：未定義だったためトークンを追加。ドロワーは右下のドックより前（z-index）に。
5. **ツールバー・ドックのセレクタ**：実際の `#saveToolbar`／`.toolbar-extra`／`#quoteActionDock .qad-btn` に合わせた（Design の `.quote-toolbar`・`#quoteDock` は仮）。かんたん／詳細の全幅の切替は既存（`.uim-switch--m`）。ブラウザ保存は「⋯」の中へ。
6. **確認ダイアログ**：`uiConfirm()` を新設（却下・マスターの解除・グループの解除・「移さない」・「チームへ移す」）。初期の焦点は「やめる」、Esc で閉じる、実行だけ赤。
7. **マスター管理の表**：個別マスターと同義グループを同じ4列に。解除は「⋯」の最下段（赤字）。承認制では解除は管理者だけ。別名の追加は、いまは表の中の入力欄のまま（「＋ 別名」ボタンへの変更は次の機会）。

## 次の依頼：スマホの明細カード（C の別案）
カード型（`tr` を grid に）は、次の機能が使えなくなるため**保留**にしています。置き場所の案をください。
- **行の操作**（見積書に出さない／要調査／入力完了／直下に追加／複製／削除）：いまは「つまみ列」にホバー（スマホは行をタップ）で出る。カードではつまみ列を隠すため届かない。
- **課税**のチェック（`td.tax-cell`）。
- **通貨**（仕・売の選択。`td.ccy-cell`）：カードで隠すと、単価の通貨が分からない。
- **利益・粗利率**（`td.profit-cell`）。
- **「その他 ▾」パネル**：カードの幅（約 360px）でどう開くか。
条件は、これまでと同じ（`id`・`onclick`・`data-*` 維持、DOM は残す、行レイアウト v3 の DOM を前提）。
