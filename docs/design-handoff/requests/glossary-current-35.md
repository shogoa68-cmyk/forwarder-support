# 現在の用語集の中身（index.html の #quoteGlossary から機械的に抜き出し・26 項目）

※ 業務上の定義はこちらで管理しているため、**文言は変えずに分類・並べ方・見せ方だけ**考えてください。
※ 右のドロワーのカテゴリチップは、いまは「全部／数量・重量／運賃・チャージ／書類・申告／取引・関係者／サーチャージ」の6つ。**分類は項目ごとのデータではなく、用語の文字から決める簡単なルール**（例：BAF・CAF・PSS・GRI＝サーチャージ、D/O・S/I・VGM＝書類・申告）で、当てはまらないものは「運賃・チャージ」に入る。分け方に無理があれば、変えてよい（コード側で直します）。

- 仕入 ＋ 乗せ幅 ＝ 売値（表の「仕」「＋」「売」）：仕＝仕入単価（サブコン・船会社などへ支払う額）、＋＝乗せ幅（上乗せする額）、売＝売値（お客様へ請求する額。仕入＋乗せ幅で自動計算）
- ※（金額の後ろ）：外貨の金額を、表の上の「換算レート」で円にして合算した目安
- パターン：サブコンの中をさらに分ける名前（任意）。同じパターン名の行が、まとまり・小計になります
- CD：Currency Difference（為替差・通貨間調整値。仕入と売値の通貨が違う行で使う、表示専用の値）
- W/M：Weight or Measurement（重量トンと容積 CBM の高い方で運賃計算するルール。主に LCL・混載貨物に適用。FCL はコンテナ本数単価が基本）
- R/T：Revenue Ton（W/M で確定した課金単位、1 R/T = 1 CBM または 1 ton。LCL・混載の運賃計算単位）
- C/W：Chargeable Weight（航空運賃の課金重量、容積重量 cm³÷6,000 と実重量の高い方）
- GP / HQ：General Purpose（一般ドライ）／ High Cube（背高 = 40HC）
- RF / OT / FR：Reefer（冷凍）／ Open Top（天井開放）／ Flat Rack（フラットラック）
- FCL / LCL：Full Container Load（1 本貸切）／ Less than Container Load（混載）
- POL / POD：Port of Loading（積み地）／ Port of Discharge（揚げ地）
- D/O：Delivery Order（荷渡指図書、輸入で D/O を切ってから引取り可）
- S/I：Shipping Instruction（船積依頼書、B/L 作成元情報）
- VGM：Verified Gross Mass（SOLAS 義務、コンテナ総重量の事前申告）
- AMS / ISF / AFR / ENS / ACID：米国／米国 10+2／日本／EU／エジプトの事前申告制度。各国「ファイリングルール」タブ参照
- サブコン：Sub-Contractor。見積の行ごとの費用の支払い先（協力会社・下請業者。集荷・通関・配送の業者、海上運賃なら船会社や NVOCC など）
- ヨコヨコ提示：マージン（乗せ幅）を乗せず、買値（仕入）をそのまま提示すること。同業者向けの見積で多い
- キャリア（契約先）：幹線輸送で運賃を契約・ブッキングする相手。船会社のほか、NVOCC やコローダーのこともある
- 実運送人（実際の船）：実際に貨物を運ぶ船会社・航空会社。例：NVOCC の△△と契約しても、実際の船は ONE ＝ キャリア「△△」・役割「NVOCC」・実際の船「ONE」
- NVOCC：自社の船を持たず、船会社のスペースを使って運送を引き受ける事業者（LCL の混載業者など）
- コローダー：自社でコンテナを仕立てず、他の混載業者のコンテナに貨物を載せて運ぶ業者
- マスター／代表名・別名：チームで共通に使う正式な名前の一覧（入力候補）。同じ会社・品名の別の書き方（略称・カナ・英字）は「別名」として代表名にまとめる。入力欄に点線の枠が付いた名前は、候補にない（未登録の）名前
- BAF / CAF / PSS / GRI：燃油／為替／繁忙期／一般運賃改定のサーチャージ
- THC：Terminal Handling Charge（コンテナターミナル取扱料）
- DEM / DET：Demurrage（CY 内保管料）／ Detention（CY 外滞留料）
- DGD / MSDS / SDS：危険品申告書／製品安全データシート
