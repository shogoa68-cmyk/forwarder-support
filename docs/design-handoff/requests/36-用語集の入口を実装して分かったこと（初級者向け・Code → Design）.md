1. **ⓘは4つではなく2つ**：「仕／＋／売」は表の上で「単価」という1つの見出しにまとまっているため、**「単価」に1つ・「課税」に1つ**にしました。単価のⓘの説明に3行（仕・＋・売）を入れています（`sample-36-hint-i.png`）。

4. **「課税」の説明**：見出しにもとからある説明（消費税10%・免税／非課税の行はチェックしない）に合わせました。「要確認」の項目のうち課税はこれで確認済みです。

## 3. お願い：［その他 ▾］の中の「設定名の下に1行の説明」（未実施）
回答では「行の［その他 ▾］の中は、設定名（MIN・幅（〜）・PS・あえて¥0 など）の下に1行の説明を常に表示」でした。実装を試す前に、見せ方を相談させてください。理由は、いまの画面（`sample-36-row-more-panel.png`）では、設定名が**横に1列のボタン**（あえて¥0／実費／PS／必要時／参考／概算／売値ベース／％／貿易条件／保険料／表示条件／MIN／幅…13個）で並んでおり、**「ボタンの下に1行」を足すと、13個の説明が横に並ぶか、縦に13行になる**からです。
- 説明の文言はすでにあります（各ボタンの `title`＝マウスを乗せたときの吹き出し。例：「PS＝代理店収益。客先見積もりには出さず、社内の利益・粗利率にのみ計上します」）。**スマホ・タッチでは吹き出しが出ない**ので、常に読める形にしたい、というのが元の目的だと理解しています。
- 案（どれか1つ、または別案）：
  - **案P：1つ選ぶと、その説明が1行だけ下に出る**。ボタンは今の1列のまま。押している（ONの）ものだけ・またはいま触れているものの説明を、ボタン列の下に1行。
  - **案Q：縦リストにする**。「設定名 ─ 説明」の2列のリスト（13行）。常に全部読める。場所を取る。
  - **案R：よく使う5つ（あえて¥0／実費／PS／必要時／MIN）だけ説明つき、残りは「もっと見る」の奥**。
- 私の推薦は**案P**です（今の見た目を壊さず、タッチでも読める）。決めてもらえれば実装します。
