# Design 回答の実装報告と確認（11）— 新規案件ボタン／管理番号入力／貿易条件／幹線輸送

2026-11-08。Design の仕様メモ（`デザイン改修仕様メモ_20261108`）と v2 回答を受けて、実装を始めました。**main に入った**のは ①新規案件ボタン（#626）と ②管理番号入力（#627）、**ブランチに入っていてマージ前**なのが ③a 貿易条件・輸送モード、③b 幹線輸送です。画像は ZIP の `images/` にあります（架空データ。現行／Industry・詳細／かんたん・PC 1400px／スマホ 390px の組み合わせ）。

いずれも `id`／`onclick`／`data-*`、保存値は変えていません（隠すだけ）。UI 契約チェック・UI スモーク（現行／Industry）・各専用テスト通過済み。

## 1. 実装したこと
### ① ダッシュボードの新規案件ボタン（`images/dash/welcome.png`）
- 主役ボタンは 1 つ（かんたん表示は「新しい見積を作る」・高さ 48px）。「自由入力で保管」「作業中に戻る」は枠だけに。
- かんたん表示：一覧の先頭に点線の「＋ 新しい見積を作る」カード、案件 0 件のときは大きな案内（手順 ①〜④）。

### ② 管理番号入力（`images/ref-*`）
- 1 カラム：ステータス（下書き中／提示済み／その他▾）→ まず入れるもの（見積番号・依頼受信日・お客様・担当者）→ 日付 → 必要なときだけ開く。
- 関連番号・メール件名は見積番号の下の任意の折りたたみ（登録があれば最初から開き、件数チップ）。提出期限は「＋ 提出期限を追加」。
- 有効期限：標準＝発行月末（チップ「標準／変更済み／SPOT」）、「変更 ▾」に 発行日の月末／翌月末／今日から＋30日／今日から＋7日／SPOT（日付に戻す動きも）。
- **新規案件だけ**依頼受信日・発行日＝今日、有効期限＝発行月末を最初から入力（既存案件は保存値のまま）。
- 取引ルール帯は自動で読み込み・**閉じたまま**「📌 取引ルール（2件・厳守1）」。開くのは手動。
- 社内メモは右下の付箋「案件名・社内メモ」に集約（ボタン `📝 案件名・社内メモ`。付箋の 1 行目の入力欄は「案件名（1行目）」）。メモ欄は画面から隠し、値は従来どおり保存。
- かんたん表示では、管理者の一時機能「作成者を指定して保存」と、空の「前の案件」案内を出さない。

### ③a 貿易条件・輸送モード（案2）（`images/cond-*`）
- インコタームズ → 方向 → 輸送モードの順に開き、選んだものは 1 行の要約（押すと選び直し）。保険付保は「＋ 保険付保（任意）」の裏（ON のときは出したまま）。

### ③b 幹線輸送（`images/route-2-*`）
- POL／POD を左のレールと点でつないだ縦表示。経由地は「＋ 経由地を追加」、キャリア・サービス名・T/T は「＋」の奥（要約チップ付き）、役割・実運送人はさらに奥。値があれば自動で開く。

## 2. 仕様から外れた・判断した点（確認をお願いします）
1. **「＋7日／＋30日」の基準**：現行は「有効期限欄の今の値から」数えていました。メニューの表記どおり**今日から**に直しました（Design の意図が「発行日から」なら教えてください）。
2. **有効期限の標準の判定**：発行日を変えると標準（発行月末）の判定も追従します。発行日が空のときは今日の月末です。
3. **「厳守」の色**：茶色は既存の Industry の警告色（`#8a5a2b`）を使い、新色は足していません。`#6b4519` が意図的な別色ならトークンとして追加します。
4. **方向・輸送モードの出し方**：インコタームズを選ぶまで方向ボタンは隠れます（Design の順序どおり）。**方向だけ先に入れたい人**がいるかもしれません。往復案件への切り替えは「方向の要約を押す」→ 選び直し、になります。緩める（方向は常に出す）案もあります。
5. **キャリアを奥に入れた**ことで、毎回キャリアを入れる人は 1 クリック増えます（Design の「キャリアはオプション」に従いました）。
6. **集荷地・配送地は未対応**：Design は幹線輸送の流れの中の「＋」にする案ですが、現行は「出発地側／幹線輸送／到着地側」の 3 枚のカード（ON/OFF・場所・デフォルトサブコン・ピース（集荷・倉庫・通関…）を持つ）で、機能が多く作り替えの影響が大きいため、そのままにしてあります。**この 3 枚をどう流れに統合するか**（例：出発地側／到着地側を「＋ 集荷地」「＋ 配送地」で開くカードにする、など）の案をください。

## 3. 画像で気づいた見た目の課題（Design の判断をお願いします）
- 「管理番号入力」の見出しの下に、中身のない細い帯が出ています（`images/ref-1-*`。見出しと本文の間）。意図した要素でなければ消す、でよいですか。
- 付箋ボタン「案件名・社内メモ」と右下の 🐞、下の固定ドック（PDF出力／プレビュー／保存）の位置関係（スマホでは重なりやすい）。
- 「自動」バッジ（依頼受信日・発行日）は初期値のままのとき出ます。**ユーザーが日付を変えたら消す**でよいですか（今は出たまま）。
- スマホ幅：1 カラム化したので縦が長くなりました。必須 3 項目を最初に見せる点は保てていますが、日付のブロックを畳む案などありますか。
