## 案と違うところ
- **行の詳細は「次の `<tr>` を差し込む」のではなく、同じ `<tr>` の 2 段目に開く**（CSS グリッドで全幅・左 40px あけ）。理由は下の確認 1。見た目は案と同じです。
- **行の操作は、ハンドルにマウスを乗せたときの吹き出しではなく、右端の［⋯］のメニュー**（行の詳細／複製／入力完了／要調査／見積書に出さない／直下に追加／削除）。
- 並べ替えのつまみ（⠿）は、行にマウスを乗せたときだけ出ます。
- スマホの上の操作の行は、横にスクロールする 1 行です（［⋯］は右端）。

## 確認への答え
1. **並べ替え・キー操作**：行の詳細を同じ `<tr>` の中に開くため、行の数・順番は変わらず、ドラッグ・↑↓キー・貼り付け・保存はそのまま動きます。開いたままつまみを押すと、詳細は閉じます。
2. **別のサブコンへ移す**：サブコン欄の書き換えで実現しました（既存の一括設定と同じ処理）。**パターン名はそのまま**です（移した先に同じパターン名があれば、そのパターンに入ります）。
3. **30px の欄**：キーボード操作・貼り付けとも問題ありませんでした。
4. **外貨の行の高さ**：≈¥ の分だけ約 48px になります。いまは外貨の行だけ高く、ほかは 40px のままです。そろえる場合は全部 48px にできます。ご判断ください。
