# 50 実装の報告への返事と、2つの答え（Design → Code）

「50 案A（費用のステップ）実装の報告と、確認への答え」への返信です。3テーマでのテストまで、ありがとうございます。

## 0. 案と違うところ：すべてそのままでよい
- 行の詳細を**同じ `<tr>` の2段目**に開く形：よい（行の数・順番が変わらない方が安全）。開いたままつまみを押すと閉じる動きもよい。
- 行の操作を右端の［⋯］のメニューにまとめたこと：よい（中身の並びもよい）。
- ⠿ をマウスを乗せたときだけ出すこと：よい（キーボードでフォーカスしたときも出す）。
- スマホの上の操作の行を横スクロールの1行に：よい。
- 「別のサブコンへ移す」でパターン名はそのまま（移した先に同じ名前があればそこへ）：よい。

## 1. 外貨の行の高さ：**今のまま（外貨の行だけ約 48px）**
- ほかの行は 40px のまま。全部を 48px にそろえる必要はない（円の金額がすぐ見えることを優先）。

## 2. スマホの［＋ 明細を追加］：**グループのいちばん下へ移す**
- サブコン見出しは**1段だけ**：名前・行数・売（円）・［⋯］。
- そのサブコンの最後のカードの下に「＋ 明細を追加」：高さ 44px・幅いっぱい・主色の文字・上に 1px の線（ボタンの枠はなくてよい）。
- 明細が0行のサブコンでは、見出しのすぐ下にこの行だけが出る。
- PC は今どおり（見出しの右の［＋ 明細を追加］）。

## 3. 画像を見て気づいたこと
1. **PC の項目名の欄が狭い**（PC_Industry.png）：項目名の欄が約 140px で、その右から数量の欄まで大きく空いている。項目名の列は「残り全部」なので、**欄も列いっぱいに広げる**（状態の札・「· 備考」は欄の右に入れるか、欄の中の右端に重ねる）。欄の最小幅は 160px。
2. **行の詳細の「カテゴリ」に欄が無い**（PC_行の詳細.png）：見出しだけで、選ぶ欄が出ていない。不具合と思われるので確認してほしい（カテゴリが未設定のときも「（なし） ▾」の選択を出す）。
3. **スマホのサブコン見出しの金額**（スマホ.png）：「2,550 USD + 80,000 JPY」と通貨が混ざって出ている。PC と同じく「**売 ¥462,500**」（JPY 換算・※付き）にし、通貨別の内訳は出さない（明細のカードには今どおり通貨と ≈¥）。
4. **上の操作の行の［要調査 1件］［完了 1/4］［一括解除］**：メモに無い部品。
   - ［要調査 N件］［完了 N/M］の札は**残してよい**（押すと該当の行へ移る、なら便利）。0件の札は出さない。
   - ［一括解除］は何を外すのか分かりにくいので、**［⋯］の中へ入れ、名前を「入力完了をすべて外す」**に（uiConfirm）。要調査も外すなら「要調査・入力完了をすべて外す」と中身をそのまま書く。
5. **❓ の重なり**（PC_行の詳細.png 右下）：PC でも ❓ が表の行（粗利の列）に重なる。42r の 5 と同じく、本文の下に ❓ の分の余白（56px）を足すか、下の合計バーの上の余白に置く。
6. **行の右端の［⋯］が薄く小さい**：点だけで見落としやすい。ほかの［⋯］と同じ**枠つき 30px のボタン**にする（行にマウスを乗せていないときも出す。色は灰のまま）。
7. （細かい点）パターン見出しの「パターン」の文字は無くてよい（🔖 で分かる）。
