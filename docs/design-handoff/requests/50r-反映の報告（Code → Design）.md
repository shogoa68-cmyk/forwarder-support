# 50r の反映の報告（Code → Design）

2026-11-24。「50 実装の報告への返事と、2つの答え」をすべて反映しました（Industry／現行／Quiet で確認・`scripts/design-tests/cost-a-test.js` 各 43 項目）。

## 反映したもの
- **1. 外貨の行の高さ**：今のまま（外貨の行だけ約 48px・ほかは 40px）。
- **2. スマホの［＋ 明細を追加］**：見出しは 1 段（名前・行数・売・［⋯］）にし、グループのいちばん下に「＋ 明細を追加」（44px・幅いっぱい・主色の文字・上に 1px の線・枠なし）。PC は今どおり。
- **3-1 項目名の欄**：列いっぱいに広げた（最小 160px）。状態の札・「· 備考」は欄の右（備考は最大 40% で「…」）。
- **3-2 行の詳細の「カテゴリ」**：お送りした写真は、カテゴリの欄が隠れていた不具合を直す**前**に撮ったものでした（直したあとは出ています）。あわせて、未設定のときの選択肢の文字を「（なし）」にしました（新しい画面のときだけ・旧い画面は「— カテゴリ —」のまま）。
- **3-3 スマホの見出しの金額**：「売 ¥462,500※」（JPY 換算・外貨があれば ※）。通貨別の内訳は出さない。
- **3-4 上の操作の行**：［要調査 N件］［完了 N/M］は残す（0 件のときは出さない・押すと該当の行へ＝もともとの動き）。［↺ 一括解除］は行から外し、［⋯］の中に「入力完了をすべて外す（N行）」（入力完了の印があるときだけ・確認つき）。この操作が外すのは入力完了の印と記録だけで、要調査は外さないため、名前は「入力完了をすべて外す」にしました。
- **3-5 ❓ の重なり**：❓ が画面の右下に浮いている間（右のレールに入っていない間）は、表の右に 56px あけて、粗利の列に重ならないようにした。
- **3-6 行の右端の［⋯］**：枠つき 30px のボタン（いつも出す・灰）。
- **3-7 パターン見出しの「パターン」の文字**：出さない（🔖 だけ）。
- **0. ⠿**：マウスを乗せたときに加え、キーボードで行・欄に焦点があるときも出す。
