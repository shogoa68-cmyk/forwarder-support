# ヘッダーと右下の常駐ボタンの整理：案B（Design → Code）

2026-11-18。要望34への回答です。**案B（右下は「？」1つだけ）で確定**。参考：`reference/Header Floating Options.dc.html`（B タブ）。※参照ファイルは描画できない前提で、必要な数字はすべてこの文書に書きます。

## 1. 方針（一言）
ご意見の入口が4か所ある状態をやめ、**右下は「？」1つ（ヘルプ・ご意見の総合窓口）**にする。☰は「表示」「画面の切替」だけに純化。アカウントはログイン前後で同じ形。機能は消さず、既存の DOM・id・onclick は残す（`#fbQuickFab` などは中身・見た目の組み替えで対応）。

## 2. ヘッダー（上）
- 左：アプリ名＋説明（今のまま）。右：**☰**と**アカウント**の2つだけ（今のまま）。
- **☰ の中身を2つの見出しに分ける**（言葉は「やること」で）：
  - 「表示」：🎨 デザインを切り替える
  - 「画面の切替」：🧭 見積入力：旧い画面／新しい画面
  - ※「ご意見」の3つ（不具合報告・アイデア・改修予定）は☰から**右下の「？」へ移す**（要素ごと移すだけ。id は維持）。
  - ☰ の `title` は「表示・画面の切替」。
- **アカウントは1つの形**：高さ40px（スマホ44px）のボタン［👤 ログイン ▾］（ログイン前）／［👤 山田 ▾］（ログイン後・名前が長いと…で省略）。ログアウト・プロフィール・チーム管理（管理者のみ）は必ず「▾」の中。本文の大きな「Google でログイン」は今のまま。

## 3. 右下の「？」（常駐は1つだけ）
- 丸 **48px**（スマホも48px・タップ44px以上）。アイコン「❓」。位置：右端16px・下16px（見積入力では下の固定部品の上に避ける。後述）。
- **押すとカード**（幅250px・ボタンの上に開く・影つき・角丸10px）：
  - 見出し「困ったとき」
  - 📖 使い方・用語集
  - 🐞 不具合・ご意見を送る（今の `#fbQuickFab` の動作＝写真・録画つきの送信）
  - 💡 アイデアを送る
  - 📣 改修予定を見る
- 閉じ方：外側を押す／Esc／「？」をもう一度。
- **確認待ちの質問が来ているとき**：「？」の右上に赤い数字の丸（最小18px・11px太字）。カード内の「不具合・ご意見を送る」の行にも同じ数字を出す。
- 印刷（プレビューの印刷）では出さない。

## 4. 初めての人への案内（吹き出し）
- 今の🐞の吹き出し＋波紋＋揺れは**やめて**、「？」の上に小さな吹き出し1つだけ：「**困ったときは「？」から**」＋小さく「1回だけ出ます ✕」。
- **ログインボタン・本文のボタンに重ねない**：PC は「？」の真上。スマホ（390px）は「？」の上・右端から16px内側に出し、本文の中央ボタンの位置まで来ない幅（最大210px）にする。重なる場合は出さない（次回以降へ）。
- 回数：**最大1回**（✕を押した／「？」を押した／約8秒表示で消える。以後は出さない）。今の「最大3回」はやめる。
- 見積入力の画面では出さない（作業の邪魔になるため）。ダッシュボード等で1回だけ。
- 見積入力の「全体リマークの跳ねる合図」は別の案件なので今回は触らない。

## 5. 見積入力での扱い
| 部品 | 新画面 | 旧画面 |
|---|---|---|
| 右下「？」 | 出す（ただし下の合計バー 48px の上＝下から 62px に避ける） | 出す（📝・右下ドックを避けて縦に並べる：下から 📝 → 「？」の順で重ならない） |
| 📝 案件名・社内メモ | **ツールバーの［⋯］の中へ移す**（右下から無くす） | 右下に残す（今のまま・「？」の下） |
| 保存／プレビュー／PDF | 上のツールバー（Design 31/32 のとおり） | 右下のドック（今のまま） |
- **固定の高さ**：固定する部品は増えない（右下の丸ボタンは `position:fixed` の浮かぶ部品で、ツールバー48px・合計バー・スマホ下固定56pxの高さ計算には含めない。スマホは「？」を下固定バーの上＝下から72pxに置く）。
- `--rms-bar`（全体リマーク取っ手バーとの避け合い）：旧画面だけ今のまま必要。新画面では取っ手バーが出ないので不要。

## 6. メモの置き場所（見た目の整理・名前だけ）
合言葉は「**誰に見える？**」。
| 名前 | いまの場所 | 見せ方 |
|---|---|---|
| **案件メモ（自分用）** | 案件名の欄の📝・付箋 | ステップ①基本の「案件名」の下に1つ。小ラベル「🔒 社内だけ」（灰）。 |
| **見積書に載せる文** | 全体リマーク・免責事項 | ステップ⑤の本文。小ラベル「📄 見積書に載ります」（青）。 |
| **この明細だけの注記** | 明細の備考／サブコン別・パターン別リマーク | 欄の名前に載る先を入れる：「備考（この行だけ）」「このサブコンへの注記」。 |
ラベルは 12px（`--text-xs`）・高さ22px・角丸999px。灰＝社内（背景 #e4e7ec／文字 #475467）、青＝見積書に載る（背景 #eef3fb／文字 #234a8f）。

## 7. 3テーマ・制約
- 色は既存トークン経由（`--bg/--text/--accent/--border/--surface`）。文字は 12／13／14／16／18px のみ。タップは44px以上。Industry は `code-overrides-industry.css` にも同じ指定を足す運用。
- 権限：チーム管理は管理者のみ（アカウントの▾の中）。メンバー（閲覧のみ／編集あり）で「？」の中身は変えない（誰でも使える）。
- 旧画面・新画面の**両方で成り立つ**（上の表のとおり）。

## 8. コードへの確認
1. 「ご意見」の3つ（☰の中）を、要素ごと「？」のカードへ移して `feedback.js` の id 操作が壊れないか。
2. `#fbQuickFab` を「？」の見た目（❓・カード開閉）に変えつつ、🐞の送信動作は「不具合・ご意見を送る」の行で呼べるか。
3. 吹き出し `#fbFabHint` の「最大3回」→「1回」への変更（`localStorage` のキーはそのままでよいか）。
4. 新画面で📝（`#qfMemoFab`）をツールバー［⋯］へ移すと、付箋ウィンドウの開き方（位置）は変わらないか。
5. スマホで「？」を下から72pxにしても、合計バー・下固定56pxと重ならないか。
6. 「使い方・用語集」の行は、今ある使い方（☰の「使い方」や見積入力の［⋯］の「使い方」）への入口でよいか（なければ今回は ☰ の「使い方」を移すだけ）。

## 9. 割り切り
- 右下に常駐物が1つ残る（旧画面では📝・右下ドックと並ぶ）。
- 「？」は🐞より意味が広く、ご意見の入口としては1段深くなる（カードを開く1タップが増える）。その代わり使い方・用語集まで1か所で探せる。
