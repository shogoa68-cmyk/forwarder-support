# 見積入力画面をシンプルにしたい — 現在の機能の洗い出し（Code → Design）

2026-11-15。見積入力画面を「シンプル」にしていきます。**かんたん表示は廃止して詳細表示に統合済み**（＝この画面が唯一の入力画面）。まず何があるかを全部出しました。**ブラウザで実際に開いた画面から機械的に拾った一覧**（画像は `27-assets/`・偽データ・PC 幅 1400px・案件 1 件を開き、明細を 3 行足した状態）。数は「ボタンや押せる部品の文字」「入力欄」を数えたもので、**重複や見えないもの（折りたたみの奥）を含みます**。

## 1. 全体の数（ざっくり）
- 画面の領域：**上部ツールバー／左端のセクションナビ／8 つのセクション（①〜⑦＋リマーク）／テーブル操作バー／右パネル＋右レール／右下の固定ボタン／下の引き出し** の 7 か所。
- 押せる部品 **約 340 個**・入力欄 **約 270 個**。**最初から見えているのは一部**で、残りは「その他 ▾」「＋〜（任意）」「必要なときだけ開く」「⋯」の奥。
- 同じ機能への入口が複数ある（例：ナビの「費用」＝右レールの「費用」＝セクション見出し／PDF 出力＝ドック＝⋯メニュー／社内メモ＝案件名の横＝右下の付箋＝⋯メニュー）。

## 3. 気づいている「重さ」（私の目視・漏れあり）
1. **同じ入口が多い**：費用・PDF・メモ・メール取込などが 2〜3 か所にある。1 か所にしたい。
2. **①管理番号入力が長い**：最初に入れるのは「見積もり番号・お客様・ご担当者・案件名」くらいだが、日付・関連番号・提出期限・タグ・REF#・参照資料・添付・取引ルール・過去の事例が同じ面に並ぶ。
3. **②貿易条件・輸送モードが 3 つの役割を 1 枚に**：条件（インコタームズ／方向／モード）／幹線輸送（POL／POD…）／出発地・到着地ゾーン。複数航路・ICD・国・荷役条件・保険付保など、使わない人が多い項目も同じ列。
4. **明細 1 行に項目が多い**：Industry では 3 段（高さ 120px）にして「その他 ▾」へ畳んだが、それでも 1 行に 12 個の入力と 20 個超のボタン。
5. **左ナビ＋右レール＋右パネル＋上ツールバー＋下の引き出し＋固定ボタン**と、画面の縁に操作が分散している。
6. **使い方の説明文**（`？`・吹き出し・「必須」「任意」の札）が多く、画面が説明で埋まる。
7. 右パネル（費用の縮小表示）は常時開いており、狭い画面で本文を押し下げる。

## 4. Design にお願いしたいこと
- **「最初の 5 分で入れるもの」だけを中心に据えた案**（私の想定：お客様・ご担当者・案件名・ルート（POL→POD）・貨物・費用の明細・出力）。それ以外を**どこへ畳むか／出すか**の整理。
- 領域ごとに「**残す／統合する／奥へ／廃止**」の判断（下の一覧を見ながら）。**廃止していい機能はユーザーに確認が要るので、候補を挙げてもらえれば私が確認します。**
- 同じ入口の**一本化**（PDF・プレビュー・保存・メモ・メール取込）。
- 明細 1 行の**最小の形**（普段見る項目と、開いて見る項目の分け方）。
- PC 幅（1100〜1920px）の案から。スマホ幅は別途（スマホは見積テーブルの一覧→シート方式が既にある）。

## 5. コード側の事情
- **機能を消すのは別の判断**。まずは「見せ方（畳む・並べ替え・一本化）」で整理するのが安全（保存データの形・出力・計算を変えない）。
- 要素ごと別の場所へ移す方式（id・onclick は不変）が使える。新しい入力項目を足すのは難しい。
- Industry／現行／Quiet の 3 テーマで崩れないこと。文字は 12／13／14／16／18px。
