## 2. 全体に共通する困りごと
1. **引き出しの高さがモジュールごとにばらばら**です。申し送り・サブコン・チャージ・費用は約 330px、金額は約 570px、比較・FCL比較・ブクマ・数量・類似は約 680px。切り替えるたびにパネルの大きさが変わって落ち着きません。
2. **見出しが二重**です。パネルの見出し（「💰 金額」など）の下に、中身の見出し（「2 費用項目」「この案件のリンク」「品名・単位の両方が一致する行が…」）がもう一度出ます。
3. **「その他 ▾」を開くと、下のボタンが画面下のバー（PDF出力／プレビュー／編集）と ❓ に隠れます**（`sample-41-fullscreen-bottom-overlap.png`：数量・行パタのボタンが ❓ の裏）。レールの縦の並びと、画面下の固定物の重なりのルールを決めたい。
4. **空の状態が弱い**：説明文だけ（比較・ブクマ・チャージ・申し送り）で、次に何をすればよいかが分かりません。
5. **作りと言葉がモジュールごとに違う**：説明文の長さ、ボタンの色・大きさ（［一括反映］は幅いっぱいの黒、［コピー］は小さな枠）、札の形がそろっていません。
6. **文字が小さい・字が細い**所がある（12px の薄い灰色の説明文、「未選択」「2行」など）。

## 3. モジュールごとの気づき
- **費用**：1 行目の「2項目 / 売 13,000 / 粗利 0.0%」が小さな灰色。［▶ すべて折りたたむ］［▼ すべて展開］が小さく目立たない。行ごとの［＋］［▼］［除外］が 3 つ並び、意味が分かりにくい。
- **金額**：項目が多く、いちばん上の「通貨別請求小計」「2 費用項目」の意味が分かりにくい。診断カードの文が長く、「要確認 1」の札が小さい。
- **申し送り**：空の状態が淡い灰色の 1 行だけ。［送信］が小さく色も薄い。誰が書いたか・日時の見せ方（コメントがあるとき）も要確認。
- **サブコン**：「現案件／過去案件」のタブはよい作り。ただ「その他」の札が行ごとに繰り返されて目立つ。［📋 コピー］の意味が分からない（何をコピーするのか）。
- **チャージ**：「輸出／輸入／通知」の 3 つの並びが何を指すか分かりにくい。「未選択」と［見積に追加］が下の端にあり、空のときは目に入らない。
- **比較**：説明文だけで、何が比べられるのか見えない。2 件以上そろわないと何も出ない。
- **FCL比較**：入力欄が多く、空欄だらけ。説明が「①②」と長い。単位・通貨も多い。
- **ブクマ**：説明文だけ。0 件のときの次の行動（内蔵リンクの取り込み）が文章の中に埋もれている。
- **数量**：説明が長く、チェック・数量・行数の欄が小さい。［一括反映］が幅いっぱいの黒で重い。
- **行パタ**：ダイアログが開く（引き出しではない）。他と作りが違う。

## 4. 作ってほしいもの
### 4-1. 共通の枠（先に）
- 引き出しの**高さのルール**（固定にする／中身で伸ばす／最低の高さ）と**幅**（今は 340px 既定・モジュール別に 400〜440px・左端ドラッグで 300〜560px）。
- **見出し**：パネルの見出し＋その下の「件数・状態の 1 行」の作り（二重見出しをなくす）。
- **空の状態**の型（アイコン＋ 1 行の説明＋ 主ボタン 1 つ）。
- **主・副ボタン**と**札（チップ）**の型。文字は 12／13／14／16／18px の 5 段。
- **レールの下端と画面下の固定物**の重なりのルール（［その他 ▾］を開いたとき）。
- 類似見積（承認済み）の作り（入口カード／ラベル付きの欄／一致の札／結果カード）と、同じ言葉づかい・色でそろえる。

### 4-2. モジュール別の画面案（共通の枠のあと）
上の表の各モジュールについて、**中身がある状態**と**空の状態**の 2 枚。スマホ幅（〜600px・下から出るシート）の確認は共通の枠で 1 枚あれば十分。優先順は：金額・費用 → 申し送り → サブコン・チャージ → 比較・FCL比較 → ブクマ・数量・行パタ。

## 5. 制約（これまでと同じ）
- 機能は消さない。**DOM・id・onclick・関数名は変えない**（クラス・包みの div／label・CSS・表示の出し分けは可）。モジュールの HTML は上の表のファイルで文字列として作っているので、置き換えやすいよう**クラス名つきの構造**で返してほしい。
- 3 テーマ（現行／Industry（基準）／Quiet）で崩れない。文字は `--text-xs/sm/base/lg/xl`。タップは 44px（スマホ・指で触る端末）。
- 引き出しは新画面（PC）では画面右から重ねて開く。旧画面では本文の横に並ぶ。
- 保存データは増やさない。レールの並び（よく使う 5 つ＋その他）と Esc で閉じる・幅の記憶は今のまま。
- 色は `#sqPanel` の変数の方式（`--sq-pri` など）を右レール全体にも広げたい。CSS は `#tab-quote-make` 配下の共通ルールに負けない書き方（`#tab-quote-make .qrc-drawer-body …` など）で。
