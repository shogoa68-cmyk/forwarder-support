# 43 サブコン見出しの整理：決定（Design → Code）

要望43への回答です。**案B（1段＋［⋯］）**を採用。画面案は reference/Subcon Header Options.dc.html（案B を選び、状態「ふだん／注記を開く／除外中／［⋯］を開く」を切り替えて見てください）。

## 0. 先に直してよいこと
- 注記の入力欄が「仕入・粗利」の文字に重なる不具合（sample-43-header-user.png）：**先に直してよい**。

## 1. 見出し（1段・高さは今のまま）
左から：
1. ⠿（並べ替え）・▼（開閉）・☐（まとめて選ぶ）…今どおり。
2. 📦 サブコン名（14px 太字・客先表示名の欄を兼ねるのは今どおり）・「3行」（12px 灰）。
3. 役割の札（FCL CARRIER など）：**枠なしの文字**（12px・やや橙の色・字間少し広め）。ボタンに見せない。
4. マスターの印（⚠ 未登録／📨 申請中）：名前の横に常に出す（今どおり）。
5. 📝 の印：注記が入っているときだけ出す。押すと注記の段（下記3）を開閉。
6. 金額（右寄せでまとめる）：**売 → 仕入 → 粗利** の順。売＝18px 太字、仕入・粗利＝13px 灰。ラベル「売」「仕入」「粗利」は 12px。「※」は売の右に小さく。合計行と同じ並び。
7. ［＋ 明細を追加］：**主ボタン**（白地・濃い文字・32px）。ほかと見た目を分ける。
8. ［⋯］：32×32px（タッチ端末は 44px）。

見出しから外すもの（［⋯］へ移す）：📇 詳細・🔖 BOOKMARK・📥 取り込み・📝 注記の入力欄・「除外／含む」・［⇅カテゴリ］。

## 2. ［⋯］の中（上から・区切り線つき）
1. 📥 取り込み
2. 📝 注記を書く
― 区切り ―
3. 📇 詳細（マスター）※登録済みのときだけ
4. 🔖 BOOKMARK ※登録済みのときだけ
― 区切り ―
5. ⇅ カテゴリ順に並べる
― 区切り ―
6. 🚫 見積書から外す（除外中は「↩ 見積書に戻す」）

各項目は、元のボタンの onclick をそのまま呼ぶ（DOM・id は残して隠すだけ）。Esc・外側クリックで閉じる。

## 3. 注記（客先表示名・サブコンへの注記）
- **見出しのすぐ下に細い段（高さ34px・薄い黄の背景）**で開く。開き方は［⋯］→「注記を書く」か、名前の横の📝。
- 段の中：「📝 注記：」＋入力欄（最大幅 520px）＋「☑ 📄 見積書に表示」＋［✕ 閉じる］。
- 注記が入っていても段は閉じておき、📝 の印だけ残す。空のときに「マウスを乗せると出る」動きはやめる。

## 4. 除外中
- 見出しと明細の行を不透明度 50% に、名前に取り消し線。
- 見出しに「見積書から外しています」の札（灰の背景）＋［見積書に戻す］（主ボタンの見た目）。
- ［＋ 明細を追加］・📝 の印・マスターの印は隠す。
- ボタン名は「見積書から外す／見積書に戻す」でよい（「除外／含む」はやめる）。

## 5. パターン見出し（FCL案／LCL案など）
- 同じ作りにそろえる（⠿▼☐・名前・金額・［⋯］）。
- サブコン見出しと見分けるため、1段小さく：背景をもう少し明るく、名前 13px、売の金額 16px。

## 6. 制約の確認
- 既存の DOM・id・onclick・保存データは変えない（隠す・移す・［⋯］から元のボタンを押す、だけ）。
- 3テーマ（Industry／現行／Quiet）・旧画面で崩れないこと。文字 12/13/14/16/18px。タッチ 44px。
- スマホ（〜600px）は対象外（#mcList）。

## 7. Code への確認
- 名前が長いとき：名前を省略記号（…）で縮め、金額と［＋ 明細を追加］・［⋯］は縮めない、でよいか。
- 1440px 未満で金額3つが収まらないとき、仕入・粗利を小さく1行にまとめる（例「仕入 ¥540,000・6.9%」）でよいか。
