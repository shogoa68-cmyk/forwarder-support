# 48 ステップ⑤「リマーク・出力」：決定（Design → Code）

**案B（①〜③とそろえる）**。共通の決まりは 00-common-layout-B.md。画面案：reference/Remark Step Options.dc.html（案B・「定型文のパネルを開く」も）。

## 左の列（文章）
1. 見出し「リマーク」（14px 太字）＋12px 灰「見積書の『リマーク』に載ります」。右端に**［＋ 定型文を入れる ▾］**（32px・副ボタン）。
   - 今の「📝 全体リマーク・免責事項」「📄 見積書に載ります」の札と「?」はやめる。
2. 文章の欄（#remarkTextarea）：最初は **6行（約120px）**、入力に合わせて伸びる（上限は画面の高さの半分、超えたら欄の中でスクロール）。
3. 欄の右下の1行：「62文字 ・ クリア」（クリアは文字ボタン・uiConfirm）。
4. 欄の下に、**入っている定型文のチップ**（主色の薄い面・✕ で外す＝今の「もう一度押して外す」と同じ処理）。
### 定型文のパネル
- ［＋ 定型文を入れる ▾］で、欄の上に重ねて開く（幅 560px・影）。外側クリック・Esc で閉じる。
- 上にタブ：定型文 ／ 区切り線 ／ チーム共有 ／ 個人（品物別は区分を選んだときだけ）。**件数 0 のタブは出さない**。ログインしていないときはチーム共有・個人を出さない。
- **「チーム人気 ⭐」はタブをやめ**、定型文タブの並びを人気順にする（人気のデータがあるとき）。
- 中身は2列の一覧（高さ 34px の行）。入っているものは主色の薄い面＋右に「✓」。押すと入る／もう一度で外す（renderRemarkPresets の点灯の仕組みをそのまま使う）。
- 右上に「🔍 探す」（任意・15個を超えたとき）。
- スマホ：下から出るシート（高さ 70%）、行は 44px。

## 右の列「見積書に添えるもの」

- 説明文は開いた中に1行だけ（常時付記：「必ず付けたい文（標準取引条件など）を選べます」）。

## 出力する（右の列の下・sticky）
- 枠：主色の薄い面・枠 #bcd0ee・角丸 8px。見出し「出力する」＋「できあがったら、ここから御見積書を出せます。」。未保存のとき橙の「● 未保存の変更があります」。
- ボタン：**［📄 PDF 出力］＝主（濃い・幅いっぱい・40px）**、下に［📋 プレビュー］［📁 ファイル N］（副・半分ずつ）。
- **［💾 保存］はこの枠から外す**（上のバーの保存＋橙の点で足りる）。※ Design 37 の「⑤にも3つ置く」を変更。
- ⑤の［次へ］は**出さない**（［← 戻る］だけ）。

## スマホ
- **横のはみ出し（約423px）は不具合として先に直す**。
- 文章の欄はステップのすぐ下で最初から見える。右の列はその下。
- 「出力する」の枠は出さない（下に固定の［プレビュー］［PDF 出力］［保存］があるため）。
- タブは横スクロールの1段。

## Code への確認
1. 入っている定型文のチップ：文章の欄を手で直して定型文の文が消えたときは、チップも消える（今の点灯と同じ判定）でよいか。
2. 作業範囲を⑤へ移すとき、御見積書の「作業範囲」の出力は今どおりか。
3. 右の列を sticky にしたとき、下の合計バー（固定）と重ならないか。
