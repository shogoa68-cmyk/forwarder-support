## 1. 共通の枠（すべてのモジュール）
```
.qrc-drawer
 ├ .qrc-drawer-head    48px：アイコン（主色）＋名前 16px 太字 ＋ 📌 ✕（32px）
 ├ .qrc-drawer-status  36px：薄い灰の面。件数・合計など（13px・大事な数字だけ太字）＋右端に短い補足
 ├ .qrc-drawer-body    flex:1・overflow:auto・余白 12px 16px
 └ .qrc-drawer-foot    下に固定（上に1px の線）：左に短い状態、右に副（文字ボタン）＋主ボタン1つ
```
- **幅**：既定 **400px にそろえる**（モジュール別の 340〜440 はやめる）。左端ドラッグ 300〜560px・幅の記憶は今どおり。
- **見出しの二重をなくす**：中身の見出し（「2 費用項目」「この案件のリンク」「品名・単位の両方が一致する行が…」）は消す。説明の段落は空の状態か、状態の1行へ。
- **グループ**（.qrc-group）：枠1px・角丸8px・頭（.qrc-group-head）は薄い灰の面・40px。行（.qrc-row）は 34〜44px。
- **文字**：13px 以上が基本。12px は補足だけ、色は --q-ink-3（#667085）より薄くしない。11px は使わない。
- **主ボタン**（.qrc-btn-pri）：主色の塗り・36px・14px 太字。**1つの引き出しに1つだけ**、下の帯の右端。幅いっぱいの黒いボタンはやめる。
- **副ボタン**（.qrc-btn-sub）：白・枠・32px。**文字ボタン**（.qrc-btn-text）：枠なし・下線。
- **札**（.qrc-tag）：20px・12px 太字・角丸4px。色は5つだけ：灰（普通）／is-pri（選んでいる）／is-ok（よい・最安）／is-warn（要確認）／is-bad（だめ）。
- **押せる選択**（.qrc-seg）：丸いセグメント（30〜32px）。選択中＝主色の薄い面＋主色の枠と文字（Design 44 と同じ）。札とは形で見分ける。
- **空の状態**（.qrc-empty）：中央にアイコン 30px（灰）＋「〜はまだありません」14px 太字＋何をすれば出るかの1〜2行（12px）＋次の行動のボタン1つ。
- **スマホ**：下から出るシート（高さ 85%・角丸14px）。枠の4段は同じ。行・ボタンは 44px。

## 2. レール（アイコン列）
### 2-1. 見た目
- 幅 64px。1つ 56×56px・角丸8px。
- **アイコン**：1色の線（20px・線 1.8px・round）。SVG をレールの部品に直接書く（外部読み込みなし）。形は reference/right-rail-mock.html の `I` と同じもの（費用＝箇条書き、金額＝¥の丸、申し送り＝吹き出し、サブコン＝人2人、チャージ＝レシート、単価比較＝天びん、FCL/LCL＝大小の箱、リンク＝しおり、類似＝虫めがね、数量＝#、行セット＝重ねた帯、その他＝点3つ）。

- **しるし**：件数＝右上の橙の丸に数字（16px・白の縁2px）、新着＝橙の点（8px）。この2種類だけ。
- よく使う5つと［その他］のあいだに細い区切り線（幅60%・1px）。

## 3. モジュールごと（images/rr-*.png）
### 3-1. 金額（K2）
- 状態の1行：「合計（JPY） **売 ¥13,000 · 粗利 0.0%**」＋右に「要確認 1」。
- 中身は3つのまとまり（グループ）：**通貨ごとの請求小計**（通貨ごとの行）／**合計（JPY 換算）**（売上・仕入・利益・粗利率）／**消費税**（課税合計・免税合計・消費税（10%））。行 36px・金額は右寄せ・粗利率が低いときは橙の文字。
- 「2 費用項目」の見出しはやめる（件数は費用の状態の1行へ）。
- 診断カード：薄い橙の箱。見出し「見積の診断」＋右に橙の札「要確認 N」。中は要点1行（● 粗利率 0.0% は低め（目安 5% 未満）。）＋「詳しく ▾」で今の全文。
- 空：「まだ金額がありません」＋［④ 費用へ］。下の操作なし。
### 3-2. 費用（K2）
- 状態の1行：「**2 項目 · 売 ¥13,000 · 粗利 0.0%**」（今の小さな灰の1行をここへ）。
- ［▶ すべて折りたたむ］［▼ すべて展開］→ 文字リンク「すべて開く／すべて閉じる」。
- 会社（グループ）の頭：▼・会社名・小計・［⋯］。**行ごとの［＋］［▼］［除外］3つは頭の［⋯］1つへ**（明細を追加・見積から外す）。
- 行：品名（13px）＋下に「仕入 ¥10,000 · 粗利 0.0%」（12px）、右に売値（太字）。行を押すと本文のその行へ移る（今どおり）。
- 下の操作：主［＋ 明細を追加］。
### 3-3. 申し送り
- 状態の1行：「**2 件**」＋右に「最新 11/19」。
- コメント：頭文字の丸（28px）＋「名前 · 日時」（12px 灰）＋吹き出し（薄い灰）。新しいものが下。
- 下の操作：入力欄（60px・2行）＋主［送る］。今の小さく薄い［送信］はやめる。
- 空：「申し送りはまだありません」＋「担当の引き継ぎや、社内への連絡を残せます。お客様には見えません。」
### 3-4. サブコン
- 状態の1行：「**1 社 · 2 行 · 仕入 ¥13,000**」。
- 「この案件／過去の案件」は .qrc-seg。
- 「その他」などの役割の札は**会社の頭に1回だけ**（行ごとに繰り返さない）。
- ［📋 コピー］は「📋 A社の行を文字でコピー」に名前を変える。
- 空：「サブコンの行がありません」＋［過去の案件から探す］。
### 3-5. チャージ
- 状態の1行：「輸出 · **1 件選択**」＋右に「全 3 件」。
- 「輸出／輸入／通知」は .qrc-seg。「通知」は「通知（A/N）」と書いて意味をはっきり。

- 空：「輸出のチャージは登録されていません」＋［マスター管理で登録 ›］。下の操作は出さない。
### 3-6. 単価比較（旧：比較）

### 3-8. リンク（旧：ブクマ）

### 3-9. 数量

## 4. CSS の方針
- すべて `#tab-quote-make .qrc-drawer …` から書く（#tab-quote-make 配下の共通ルールに勝てる）。!important は使わない。
- 色は .qrc-drawer に変数を置き、テーマごとに上書き（#sqPanel の方式を右レール全体へ）：
```
#tab-quote-make .qrc-drawer, #tab-quote-make .qrc-rail{
  --rr-pri:#2f5fb3; --rr-pri-50:#eef3fb; --rr-pri-200:#bcd0ee;
  --rr-ok:#067647; --rr-ok-50:#ecfdf3; --rr-warn:#b54708; --rr-warn-50:#fffaeb; --rr-bad:#b42318; --rr-bad-50:#fef3f2 }
/* 現行テーマ＝--accent 系、Quiet＝--q-accent 系で上書き。#sqPanel の --sq-* は --rr-* を参照する形にそろえる */
#tab-quote-make .qrc-drawer{display:flex;flex-direction:column;top:var(--toolbar-bottom);bottom:var(--totalbar-h);width:400px}
#tab-quote-make .qrc-drawer-head{height:48px}
#tab-quote-make .qrc-drawer-status{min-height:36px;padding:0 16px;background:#f8f9fb;border-bottom:1px solid var(--border);font-size:var(--text-sm)}
#tab-quote-make .qrc-drawer-body{flex:1;overflow:auto;padding:12px 16px}
#tab-quote-make .qrc-drawer-foot{border-top:1px solid var(--border);padding:10px 16px;display:flex;gap:8px;align-items:center}
#tab-quote-make .qrc-rail-item{width:56px;height:56px;border-radius:8px;color:var(--text-md)}
#tab-quote-make .qrc-rail-item svg{width:20px;height:20px;stroke:currentColor;fill:none;stroke-width:1.8;stroke-linecap:round;stroke-linejoin:round}
#tab-quote-make .qrc-rail-item.is-on{background:var(--rr-pri-50);color:var(--rr-pri);box-shadow:inset 0 0 0 1px var(--rr-pri)}
#tab-quote-make .qrc-rail-label{font-size:var(--text-xs);font-weight:600}
```
- 各モジュールの HTML 文字列（ui.js・subcon-insert.js・local-charges.js・compare.js・fcl-lcl.js・bookmarks.js・scenario.js・lc-row-pattern.js）は、1 の4段の包み（head／status／body／foot）とクラス名で返す。id・onclick・関数名は変えない。

## 5. 制約の確認
機能は消さない。DOM・id・onclick・関数名は変えない（クラス・包みの div・CSS・表示の出し分けだけ）。保存データは増やさない。レールの並び（よく使う5つ＋その他）・Esc で閉じる・幅の記憶は今どおり。3テーマ・旧画面（本文の横に並ぶ）でも崩れない。

## 6. Code への確認
1. 行セットを引き出しに移すとき、今のダイアログ（パターン管理）の編集機能（並べ替え・名前変更）も引き出しの［⋯］に入れてよいか。
2. 金額の「通貨ごとの請求小計」は、通貨が1つ（JPY だけ）のときは畳んでよいか。
3. レールの名前の言い換えで、用語集・❓の説明・ツールチップの文言をまとめて直せるか。
4. 下の合計バーの高さ（--totalbar-h）は、1500px 以上（ボタンが減る）とそれ未満で同じか。引き出しの bottom に使うため。
