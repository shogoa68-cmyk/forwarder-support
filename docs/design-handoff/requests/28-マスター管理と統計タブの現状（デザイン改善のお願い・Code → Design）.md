# マスター管理タブ・統計タブの現状（デザイン改善のお願い・Code → Design）

2026-11-16。上段タブ「🗂 マスター管理」（`#tab-master`）と「📊 統計」（`#tab-stats`）の **PC 版**のデザインを改善したいので、現状をまとめます。**3 案くらい方向の違う案**を出してください（選んだ案をコードに落とします）。
スマホ版は別途対応済み（統計＝要望 14／マスター管理＝要望 15。〜600px の薄い表示層）。今回は **PC（600px 超）が主**で、スマホ版と矛盾しない方向でお願いします。

画面写真は同じフォルダの `sample-28-*.png`（偽データ・Industry テーマ・PC 幅 1400px）：
- `sample-28-stats-top.png`（統計の上部＝ツールバー・数字カード・タブ 14 個）／`sample-28-stats-customer.png`（名寄せ＝お客様）／`sample-28-stats-ledger.png`（明細台帳）／`sample-28-stats-winrate.png`（受注分析）
- `sample-28-master-approval.png`（マスター管理の上部＝件数・ゆらぎ・移行の案内・申請）／`sample-28-master-detail-modal.png`（詳細ポップアップ）／`sample-28-master-list.png`（一覧のカード表示。撮れていなければ省略）

## 1. 2 つの画面の役割（一言で）
| 画面 | 役割 | 主な使い手 |
|---|---|---|
| 📊 統計 | 見積案件・明細を**集計**して、①入力された名前の**ゆらぎを見つけてマスターに寄せる**②受注・粗利を**分析**する | 管理者・メンバー（見るだけも多い） |
| 🗂 マスター管理 | 正しい名前（マスター）・別名・詳細情報（担当者・国・種別…）を**登録・保守**する／申請の承認／ゆらぎの自動チェック | 管理者が中心（メンバーは申請・閲覧） |

2 つは**つながっている**：統計で見つけた「ゆらぎ」を「☆マスターに登録」「→別名にする」で直し、その結果がマスター管理に並ぶ。今は別タブで、行き来しづらい。

## 2. 統計タブの現状（PC・上から）
1. **ツールバー**：期間（全期間／今年度／直近3ヶ月／今月）・🔄集計・クラウド状態の札・「? 使い方」
2. **数字カード 6 枚**：プリセット数／明細行数／SV・キャリア種類／品名グループ数／ゆらぎグループ／マスター候補数（押しても何も起きない飾りに近い）
3. **タブ 14 個**（1〜2 段に折り返す・見出し「集計・分析」）
   - 名寄せ・マスター：🏢サブコン／🚢キャリア／👤お客様／📝品名／📐単位／💰チャージ
   - 分析：🔗サブコン×港／🧾お客様×品名／📒明細台帳／🎯マージンばらつき／🎲受注分析／🔖パターン別
   - 指標：📊データ／🎯KPI（準備中）
4. **タブの中身**：ほぼ全部が**表**。名寄せ系は「並び替え（件数順／名前順）・未整理のみ・ゆらぎありのみ」＋説明帯＋表（名前／件数／担当者／ステータス／操作＝☆登録・☆マスターに登録・→別名にする）。分析系は専用の表・絞り込み・並び替え。

### 困っていること（使っている側の声・観察）
- 14 タブが横に並ぶだけで、**何をする画面か**（名寄せ＝直す、分析＝見る）の区別が弱い。
- 数字カードが大きい割に情報が少なく、**押せるのか分からない**／押しても進めない。本当に見たい「今やること（ゆらぎ N 件・未登録 N 件）」への導線になっていない。
- 名寄せの表は 1 行に**ボタンが 3 つ**（☆登録／☆マスターに登録／→別名）で意味が違う（PC では別の操作）のに見た目が似ている。
- 分析の表は文字が小さく、**一番大事な数字（受注率・粗利率）が埋もれる**。グラフはほぼ無い（受注分析に横棒を出したい）。
- 空の状態（データなし・未ログイン）の見た目が素っ気ない。
- 3 つのテーマ（現行／Industry／Quiet）で見た目の格が揃っていない。

## 3. マスター管理タブの現状（PC・上から）
1. 小タブ：⭐マスター管理／🔀エイリアス是正（過去データの一括置換）
2. 見出し「🗂 マスター管理」＋管理者の札＋「← 見積もりに戻る」
3. **件数タイル**：承認待ち N／マスター N／うち別名あり N
4. **🔍 ゆらぎチェック**カード：自動チェックの最終実行・要確認の数・「今すぐチェック」
5. （条件付き）「このブラウザにだけ保存されているデータがあります」の移行の案内
6. **📨 マスター・別名の申請（承認待ち）**表：種別／名称／申請者／承認・却下
7. **検索ボックス**（名前・別名・詳細の中身を横断）＋ 種別チップ（すべて／サブコン／お客様／品名／港／単位／ICD）＋ **「＋ マスターを新規登録」**
8. 種別ごとの**絞り込み**（サブコン＝種別・得意エリア・所属グループ／お客様＝取引形態・タグ／港＝地域→小地域→国…）と**並び順**（名前順／種別・タグごと／取引形態ごと／所属グループごと／得意エリアごと）
9. **一覧＝カード表示（サブコン・お客様のみ・最大 3 カラム）**：会社名（クリックで詳細チップが開閉）・取引形態の色（荷主＝青／同業者＝橙／海外代理店＝紫／乙仲＝青緑／その他＝灰）・印（📌取引ルール／🗂顧客カルテ／📰ニュース／🔗先のお客様／🤝紹介／🔁互恵）・「詳細」「⋯」。同業者のカードの中に「先のお客様」を入れ子で表示。港・品名・単位は従来の表（リスト）表示。
10. **詳細はポップアップ**（幅 980px・高さ固定）：お客様はタブ（担当者／会社の詳細・タグ／取引ルール／ニュース・顧客カルテ／メモ・添付）、サブコン・港などはタブなしの 1 枚フォーム。
11. 新規登録もポップアップ（種別ごとの詳細フォームつき）。

### 困っていること
- 画面の**上部がお知らせ・カード・申請で縦に長く**、本題の一覧に着くまで 1 画面分スクロールする（管理者ほど長い）。
- 一覧の**種類ごとに見た目が違う**（カード／リスト）うえ、絞り込みが段になっていて、今どの条件で絞っているかが分かりにくい。
- カードは情報が多く（印が最大 6 種）、**どれが重要か**の優先順位が弱い。
- 詳細ポップアップの**タブが多く**、保存ボタンが下で、編集中かどうかが分かりにくい。
- 「統計で見つけたゆらぎ」→「ここで直す」の行き来が不便。

## 4. お願いしたいこと
- **3 案くらい**（紙芝居でも HTML でも可）。観点の例：
  - 2 画面を**統合／ハブ化**する（例：左に種別、右に「今日やること＋一覧」。統計の名寄せはマスター管理の中へ）／別々のまま整理する、のどちらが良いか
  - 統計の**数字カードを「今日やること」へ**変える・押して進める
  - 名寄せの 1 行の**操作を整理**（主操作 1 つ＋「⋯」）。☆登録と☆マスターに登録の統一の可否
  - 分析の**見せ方**（要約の数字を大きく・横棒グラフ・並び替え・絞り込みの置き場所）
  - マスター管理の**上部を軽く**（ゆらぎ・申請・移行の案内を 1 本の「通知帯」に畳む 等）
  - 一覧の**絞り込み・並び順の置き場所**（今の条件が一目で分かる・クリアしやすい）
  - 詳細ポップアップのタブ数・保存の見せ方
- **優先して見たい画面**：①統計の名寄せ（サブコン／お客様）②受注分析③マスター管理の一覧（お客様・サブコン）④マスター管理の上部（件数・ゆらぎ・申請）
- 各案の**良い点・割り切り**を一言ください。

## 5. 守ってほしい制約
- **機能は消さない**（隠す・畳む・移すのは可）。既存の DOM・`id`・`onclick` を残して CSS／薄い表示層で組み替える方針（コードはこの方針で何度も改修済み。見た目の入れ替えは得意）。データの保存形式は変えない。
- 3 つのテーマ（現行／Industry（既定）／Quiet）で崩れないこと（色は共通トークン）。
- 文字は 12／13／14／16／18px の 5 段（`--text-xs/sm/base/lg/xl`・スマホは一段大きい）。
- スマホ幅（〜600px）には**別の表示層が既にある**（統計＝「今日の確認」、マスター管理＝「今日やること」）。PC の案がそれと**同じ考え方**（今日やること中心）になると嬉しい。
- 画面下の「← 見積もりに戻る」・🐞 常駐ボタンと重ならない余白。
- 取り消しにくい操作（登録・別名・一括置換・却下）は確認の入れ方も案に含める。
- 管理者／メンバー（承認制では「申請」になる）／閲覧のみ で出るボタンが違う点に注意。
