## 2. 決めてほしいこと：参照資料と一時ファイルの置き場が2つある
同じ「案件に紐づくファイルを置く場所」が、寿命と用途だけ違って2つあります。使う人が迷います。

| | 参照資料（管理番号入力の中） | 一時ファイル（⑤の出力枠・引き出し） |
|---|---|---|
| 消えるまで | 14日 | 3時間 |
| 置けるもの | ファイル（25MB）＋ URL | ファイル（25MB・50個・100MB） |
| 用途 | 案件の根拠・参考（社内） | 見積に添えて送る資料（手元にダウンロードして添付） |
| 保存先 | `quote_attachments` | `quote_temp_files`（3時間はサーバー側で強制） |

案：
- **案X（統合）**：置き場を1つにし、追加するとき「3時間だけ置く／14日置く」を選ぶ。一覧も1つ。入口は⑤（出力）と①の「参照資料」の両方から同じ画面へ。
- **案Y（分けたまま、言葉と位置だけ整理）**：参照資料＝「案件の資料（14日）」、一時ファイル＝「送付用（3時間）」と名前と説明を分け、①には参照資料だけ、⑤には送付用だけを置く。
- **案Z（現状維持）**。

Code の見立て：案X は保存の仕組み（表・容量・期限）をまとめ直す大きめの工事。案Y は文言と配置だけで小さい。まず案Y、様子を見て案X、でも良いと思っています。どれが良いか、画面案もお願いします（ダイアログの「追加」画面に期間の選択をどう置くか／一覧に残り日数をどう出すか）。

## 3. 制約
機能は消さず、DOM・id・onclick は残す（表示の出し分けと配置だけ）。3テーマ・文字は 12／13／14／16／18px・タップ 44px。保存データは増やさない（左レールの開閉の記憶だけ端末に保存）。旧画面は対象外。
