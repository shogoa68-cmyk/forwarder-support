# 「使い方・用語集」を、どの画面からでも引けるように（初級者向け・Code → Design）

## 1. いまある説明の仕組み（確認できたこと）
1. **用語の説明ドロワー**（右から開く。画像1枚目）：検索欄＋カテゴリのチップ（全部／数量・重量／運賃・チャージ／書類・申告／取引・関係者／サーチャージ）＋用語の一覧。**一度開くと、別のタブに切り替えても開いたまま**（画像2枚目）。
   - ただし**開く入口は見積入力の中だけ**：①ツールバー［⋯］の「このタブの使い方・機能説明」（操作ガイド／用語集／ショートカット一覧） ②明細テーブルの見出し近くの「📖」ボタン。
   - ドロワーになるのは Industry テーマ（既定）だけ。「現行」テーマでは、使い方の中の用語集の場所へスクロールするだけ。
   - 分類は項目ごとのデータではなく、用語の文字から決める簡単なルール（BAF・CAF・PSS・GRI→サーチャージ、など）。
2. **各タブの先頭の折りたたみ「使い方」**：全部で40か所。タブごとに別々の文章。
3. **明細テーブルの列見出し**（「仕／売」「仕入＋乗せ幅＝売値」「課税」など）には、**マウスを乗せると出る吹き出し（`title`）**が付いている。タッチ端末では見えない。
4. 入力欄の横の細かい説明は「？」に格納してある（押す／乗せると吹き出し）。
5. **全画面共通の「使い方」の入口は無い**。右下の「❓」のカードにも、まだ入れられていない。

## 2. 困っていること
**コードと画像で確認できたこと**
- 用語集に**入る道が見積入力の中だけ**。計算・書類・Booking/SI などのタブで「R/T って？」と思っても、そこからは開けない（先に見積を開く必要がある）。
- 「使い方」が40か所に分かれていて、**「どれを開けばいいか」を選ぶ入口が無い**。
- 明細の列見出しの説明は、**マウスを乗せたときだけ**。スマホでは読めない。

**初級者の目線での推測（実機での確認はまだ）**
- 明細の「仕」「売」「＋」の1文字は、新人には通じない。「その他 ▾」の中の MIN・幅・PS・あえて¥0 なども、名前だけでは意味が分からない。
- 用語集が「略語の辞書」のままで、**「いまの画面で何をすればいいか」には答えていない**。

## 3. お願いしたいこと
**A. 入口**（右下の「❓」カードの1行目「📖 使い方・用語集」を押したときに、何が開くか）
- **2〜3案**。観点の例：
  - 全画面共通の「**用語の説明**」ドロワー（いまの検索＋チップを、どの画面からでも開ける形に）
  - 「**この画面の使い方**」への近道（いま見ているタブの「使い方」を開く／該当位置へ移動する）を、用語集と1つの入口にまとめる
  - 初めての人向けの「**最初の一歩（3つ）**」（ログイン→見積を作る→出力、など）を入口の最初に置く
  - 「現行」テーマでも同じ入口が成り立つこと
- **優先して見たい状態**：①ダッシュボード（初めて開いたとき）②見積入力（新画面）③計算タブ ④スマホ幅 ⑤検索して0件のとき ⑥用語を探したあと、元の作業に戻る（ドロワーを開いたまま作業できる）

**B. 専門語のその場説明**（見積入力）
- 明細の「仕／売／＋乗せ幅」「MIN」「幅（〜）」「PS」「あえて¥0」「課税」を、**マウスがなくても（タッチでも）読める**見せ方。
- 例：列見出しの小さな「ⓘ」を押すと1〜2行で説明が出て、続けて「用語の説明を開く」へ進める。行の「その他 ▾」の中の各設定名の下に1行説明を出す。
- 説明文は新人向けの言い回し（例：「仕＝仕入（サブコンなどへ払う金額）」）にしたい。**文言案も出してもらえると助かります**（業務上の正しさはこちらで確認します）。

- 各案の**良い点・割り切り**を一言ください。

## 4. 守ってほしい制約
- **機能は消さない**。既存の DOM・`id`・`onclick` を残して、CSS と薄い表示層で組み替える方針です。用語集の本文は `#quoteGlossary` の直後の `<ul>` 1か所が元データで、ドロワーはそこから作っています（**用語を足す・直すのは1か所**にしたい）。
- 「❓」カードは幅250px・1行44px以上。**カードの1行目に入る文言と、押したあとの動き**を決めてください。
- **3つのテーマ**（現行／Industry（既定）／Quiet）の共通トークンで色を指定。文字は12／13／14／16／18px（`--text-xs/sm/base/lg/xl`）。タップは44px以上。
- 印刷では出さない。保存するデータは増やさない（見るだけの機能）。
- 見積入力は旧画面と新画面の両方が残っています。列見出し・行まわりの案は、**両方で成り立つ**か、**新画面だけ**かを書いてください。
- 固定の高さ（上のツールバー48px・下の合計バー・スマホの下固定56px）は増やさない。ドロワーは「重ねて開く」方式で（本文を押し縮めない）。
