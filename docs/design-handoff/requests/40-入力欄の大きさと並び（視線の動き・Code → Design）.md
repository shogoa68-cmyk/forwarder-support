## 1. 全体の問題と案
1. **高さの統一**：PC は 36px（スマホ 44px）にそろえる案。ボタン（自動採番・変更▾・％関税率など）も同じ高さで欄の横に付ける。
2. **右端・左端の統一**：本文の幅（いま 1000px）の左右に、入力欄・［戻る］［次へ］・⑤の「出力する」の枠をそろえる。
3. **幅を中身の長さに合わせる**（幅は「何文字くらい入るか」のヒントになるため）。目安案：
   | 種類 | 幅 |
   |---|---|
   | 見積もり番号・HS コード | 200 |
   | 日付 | 170 ／ 時刻 110 |
   | 国 | 170 ／ 港 340 |
   | 会社名 | 420 ／ 担当者 260 |
   | 案件名・貨物名 | 本文の幅いっぱい（長くなるため） |
   幅を詰めると右に空きができます。**2 列の格子（左列 420＋右列 420 など）にそろえる**か、**空きをそのままにする（左揃えで縦に読む）**か、Design の判断をください。
4. **見出しの二重**：本文の見出し「1 基本 未入力」の下に、セクション見出し「🗂 管理番号入力」がもう一度。下を小見出し（14px）にしたが、まだ 2 段に見える。消してよいか。

## 2. ステップごとの問題と案
### ① 基本（`sample-40-step1.png`）
- **1 行目が「自動で入る欄」（見積もり番号・依頼受信日）**。目が最初に止まる場所に、入力しなくてよい欄がある。本当に入れるお客様名・担当者は 2 行目。
  - 案：1 行目［お客様名称｜ご担当者］→ 2 行目［案件名］→ 3 行目［見積もり番号（自動）｜依頼受信日（自動）］を小さく。
  - 気になる点：見積もり番号は社内で「最初に確認する番号」でもある。上に残すなら、**表示だけ（自動）にして、欄は「変更」で開く**案もある。
- ご担当者の例文（「例）山田 ※宛先（お客様側）の氏名。出力時に自動で『様』付与」）が長く、欄に収まりきらない。→ 説明は「？」へ、例文は「例）山田」だけ。
- 「＋ 関連番号・メール件名を追加（任意）」が見積もり番号とお客様名のあいだに入り、行の流れが切れる。→ ①の最後（［その他の情報］の中）へ。
- 案件名の右の［📝 社内メモ］は、案件名の欄の一部に見える。→ 欄から離す、または案件名の見出しの横へ。

### ② ルート（`sample-40-step2.png`）
- 並び（貿易条件→方向→出発地→幹線→到着地）は**荷物が動く順**で分かりやすい。変えない。
- POL・POD の欄が **広すぎ（788px）・低すぎ（24px）**。そのため「🌐 国」が右端（1055px）に押し出され、港と国のあいだを目が大きく往復する。
  - 案：港 340px・国 170px を**隣り合わせ**に。国は「港の候補を絞る」ための欄なので、**国を港の左に置く**案もある（左→右に「国を選ぶ→港を選ぶ」）。ただし港名から国を自動で入れる動きもあるので、どちらが自然か判断をください。
- 貿易条件が 2 回出ている：上の帯「貿易条件 EXW（工場渡し）」と、下のボタン「インコタームズ EXW ✎」。→ どちらか 1 つに。

### ③ 貨物・物量（`sample-40-step3.png`）
- 貨物名（841px）・HS コード（613px）が高さ 44px で太く、他のステップ（30px）と違う。HS コードの右の［％ 関税率］［関連知識・他法令 11］［WEBタリフ↗］が遠い。
- 「クリア」ボタンが貨物情報と物量情報のあいだにぽつんとあり、**何を消すのか分からない**。→ 貨物情報の見出しの右端へ、文言を「貨物情報をクリア」に。
- 航空・LCL では荷姿（個数・寸法・重さ）が主な入力なのに、［荷姿・換算・シミュレーターなどの詳細 ▾］の奥に隠れている。FCL ではコンテナ本数が主。→ **輸送モードで先に出すものを変える**案（FCL＝コンテナ、LCL・航空＝荷姿）。

### ⑤ リマーク・出力（`sample-40-step5.png`）
- いちばん上が「📦 品物別リマーク」の選択（めったに使わない）。いちばん使う**文章の欄が 3 段下**（定型文のタブ・ボタンの下）。
  - 案：①見出し → ②定型文のタブとボタン → ③文章の欄 → ④品物別リマーク・常時付記・画像を添付（任意のものをまとめて下へ）。
- 「クリア」（左）と「0文字」（右）が欄の下で離れている。→ 欄の右下に「0文字・クリア」をまとめる。
- 「出力する」の枠が本文より 100px 右に出ている（上の 1-2）。

## 3. 決めてほしいこと
1. 欄の高さは 36px（PC）／44px（スマホ）でよいか。
2. 幅を中身に合わせたあとの右の空き：2 列の格子にそろえるか、空きのままか。
3. ①の 1 行目をお客様名にする（見積もり番号を下げる）か。
4. ②の国は港の左か右か。
5. ③の「モードで先に出すものを変える」をやるか。
6. ⑤の並び替え（文章の欄を上へ）でよいか。

## 4. 制約
- 既存の DOM・id・onclick・保存データは変えない（並べ替えは CSS の `order`・グリッド、または要素ごと移すだけ）。旧画面は対象外（新画面のみ）。
- 3 テーマ（Industry／現行／Quiet）で崩れないこと。文字は 12／13／14／16／18px。
