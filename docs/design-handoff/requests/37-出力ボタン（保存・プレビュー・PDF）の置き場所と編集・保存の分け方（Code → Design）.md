# 出力ボタン（保存・プレビュー・PDF）は右上で良いか／編集と保存の分け方（Code → Design）

2026-11-18。見積入力の新画面（既定にした）で、「保存・プレビュー・編集のボタンは右上で本当に良いか」を、4 人の見直し役（レイアウト・UI 批評・新人・実務者）と私の見立てで確認しました。**結論：右上に置くのはこのままで良い。ただし 4 点は直したほうが良い**と考え、先に Code 側で直しました。Design の目で見て、違うと思う点があれば教えてください。サンプルは `sample-37-*.png`。

## 1. 右上のままで良いと考えた理由
- 保存は右上、が多くのアプリ（文書・図形ツール）と同じで、慣れた人は探さずに済む。
- 上のバーは画面に固定してあり、下へスクロールしても押せる。旧画面の右下ボタンより、入力する場所からの目の動きが短い（実務者のレビュー）。
- スマホは下に固定して親指で押せるので、今のまま。

## 2. 直した 4 点（Code 側で実装済み・新画面のみ）
| # | 問題 | 直したこと |
|---|---|---|
| 1 | ステップ⑤の名前が「リマーク・出力」なのに、出力ボタンは遠い上のバーにしかない | ⑤の最後（［← 戻る］の上）に「出力する」の枠を足し、［📄 PDF 出力］［📋 プレビュー］［💾 保存］をもう一度置いた。上のバーのボタンは残したまま、同じ処理を呼ぶだけ。`sample-37-step5-out-pc.png`／`-sp.png` |
| 2 | 同じボタンが、閲覧中は「編集」・編集中は「保存」と意味を変える（押し間違い） | ［💾 保存］はいつも「保存」の文字にして、閲覧中は押せない（うすくなる）。閲覧中だけ、別のボタン［✏️ 編集を始める］を保存の左に出す。他の人が編集中・閲覧のみ権限のときは［🔒 閲覧のみ］（押せない）。 |

## 3. Design に見てほしいこと（任意・意見がなければ今のままで進める）
1. **ボタンの順番と強さ**：今は左から［PDF 出力（濃い）］［プレビュー（青灰）］［保存（濃い）］。保存は一番よく押し、PDF は仕上げの 1 回。**PDF と保存が同じ濃さ**になっている。主ボタンは 1 つ（保存）にして、PDF・プレビューは白地＋枠の副ボタンにするほうが良いか。
2. **［✏️ 編集を始める］の置き場所**：保存の左・白地＋青い枠にした。閲覧中は「保存」がうすくなるので、2 つ並ぶ。この見た目で伝わるか。
3. **橙の点**：12px・保存ボタンの右上。小さすぎ／目立ちすぎはないか。
4. **⑤の「出力する」の枠**：薄い青の枠・見出し「出力する」・説明 1 行・ボタン 3 つ。文言や強さの調整案があれば。
5. **プレビューを下の合計バーのそばに置く案**（通販のレジ画面のように「金額を確かめる場所のそばに次へ進むボタン」）。固定の帯が増えるので今回は見送ったが、やったほうが良いか。
