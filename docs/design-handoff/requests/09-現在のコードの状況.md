## C. 付録：かんたん表示のレビュー結果（棚上げ中・参考）
画像：`images/dashboard/`・`images/editor-simple-industry/`・`images/others-industry/o6-…o7-…`（スマホ幅）。
- 新人：費用テーブルの 1 行目が薄くて入力欄に見えない／「サブコン・パターン・カテゴリ」「仕入＋乗せ幅＝売値」の説明がない／「必須」が 5 か所で優先が見えない／ヘッダーのボタンが多い（4 つ＋🐞）。

- 上級者：**出力前の確認に有効期限・危険品・免責が入っていない**（コードで確認済み）／危険品が「詳細（任意）」内に畳まれている／免責・全体リマークが既定で畳まれ「任意」表示。

## E. 守る条件（これまでと同じ）
`id`／`onclick`／`data-*`／JS が付け外しする class は維持する。機能は廃止しない（隠す＝DOM に残す）。キーボード操作（↑↓キー移動・Tab 順）を壊さない。詳細／かんたん、現行／Industry の両対応。客先向け出力（御見積書・メール）は対象外。行の DOM は `<template id="row-tpl">`（`index.html`）で、`tbody` の子は「明細行／付随行／仮想行」の 3 種（**別の `<tr>` を増やす実装は危険**）。
