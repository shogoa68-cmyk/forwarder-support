## 3. 幹線輸送の「航路」の一覧：**カード**
### 3-1. 1航路＝1枚のカード
- 見出しの行：⠿（並べ替え）・**案の名前**（14px 太字。無いときは灰の「案名なし」＋文字リンク「＋ 名前」）・採用の札・右に「✎ 直す」と［⋯］。
- 2行目：「キャリア · POL → （経由） → POD · T/T」（13px）。
- 区間があるとき：縦の流れ（点・区間名〈集荷／海上／配送〉・業者・ETD）を12px で。海上の点だけ主色。無いときは文字リンク「＋ 区間を足す」。
- **採用の1本**：緑の枠＋左に 3px の緑の線＋緑の札「✓ 採用」。**不採用**：カード全体を 60% の薄さ＋灰の取り消し線の札「不採用」。**未定**：札なし。
- 外に出す操作は「✎ 直す」と「採用にする」（不採用・未定のカードだけ・文字リンク）の2つ。ほかは［⋯］：案の名前を変える・区間を直す・使用不可にする・上へ／下へ・削除。
- 一覧の見出し：「航路」（14px 太字）＋「N 本 ・ 見積書に出すのは『採用』の 1 本」（12px 灰）＋右に［＋ 航路を追加］。
### 3-2. 入力欄との関係
- **航路が1本もないとき**：今の POL／POD・キャリアの入力欄をそのまま（＝1本目の航路を入れる欄）。
- **1本以上あるとき**：入力欄は畳み、［＋ 航路を追加］で一覧の下に点線の箱で開く（POL→POD の点の流れ・キャリア・案の名前・T/T・［この航路を登録］・キャンセル）。✎ 直すも同じ箱を、そのカードの場所に開く。
### 3-3. 採用と出力：**「採用」1つにまとめる**
- 「使う ✓」と「採用」の2つの印をやめ、**「採用」が見積書への出力を決める**（採用は1本だけ。別のカードを採用にすると、前の採用は未定に戻る）。
- 1本しかないときは、自動で採用（印は出すが、操作は不要）。
- ※ **お客様に渡る書類が変わる**変更なので、入れる前に今の見積（「使う ✓」が複数付いているもの）がどう変わるかを確かめてほしい（下の確認1）。

## 4. マスター管理のスマホ
1. **新規登録**：下から出るシート（角丸14px・高さは中身まで）。1列で ① 種別（丸いチップ 36px：サブコン／お客様／港／ICD／品名…）→ ② 名前 ＊（44px）→ ③ 詳細（任意・畳む：別名・ふりがな・国・担当など、種別で中身が変わる）。［登録する］はシートの下に固定。
2. **エイリアス是正**：**PC だけ**。スマホでは入口を残し、押すとカード「🔧 表記の是正：古い表記をまとめて直す画面は、PC で開いてください（多くの案件を書き換えるため）。」を出すだけ。
3. **解除の確認**：件数を出す。題「『{名前}』をマスターから解除しますか？」、本文「この名前を使っている案件：N 件／案件の中の表記はそのまま残ります（マスターの候補に出なくなるだけ）。」、ボタン［やめる］［解除する］（赤）。確認は uiConfirm。
4. **先のお客様（入れ子）**：「🔗 先のお客様 N社 ▾」でカードの中にその場で開く（1段だけ・左に細い線）。各社「名前 · 案件数」、3社まで出して「すべて見る（N社） ›」。
5. **通知（トースト）の場所**：スマホは**画面の上（ヘッダーのすぐ下）の1か所**。左右 12px・角丸8px。同時に出るのは2つまで（新しいものが上）・4秒で消える・押すと消える。通知が出ている間は ❓ の吹き出しを出さない。下からは出さない。

## 5. 統計のスマホ

## 6. 見積入力の「旧い画面」：**期限を決めずに残す**
- ☰ の「画面の切替」も今のまま。お知らせは出さない。
- その代わり、**新しい機能・見た目の改修は新しい画面だけ**（旧い画面は動く状態を保つだけ・直すのは不具合だけ）。旧い画面で新しい機能が見えないことは、☰ の切替の横に小さく「旧い画面では一部の新しい機能は使えません」と書く。
- 廃止を決めたときの文面の案は、reference/Remaining Decisions 42 の「1か月で廃止」に残してある。

## 7. サブ案件をやめたあとの表示：**ii「関連」の1種類にする**
- カードの入れ子と「↳ サブ：○○」をやめ、カードには「🔗 関連 N件」の札だけ（メイン・サブどちら側でも）。
- 番号の (A)(B) は**残す**（番号は変えない・保存データも変えない）。
- 類似見積の引き出しの「🔗 関連付けた案件」では、元のメイン／サブの組も「関連」として並べる（位置づけの切替は出さない）。
