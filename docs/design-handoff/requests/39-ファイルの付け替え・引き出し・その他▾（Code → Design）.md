## 1. 送付用 ⇄ 社内の「付け替え」
いまは付け替えできず、削除して置き直します（回答の「今回は不要」を採用）。実際には「送付用で置いたが、やはり社内の資料として残したい（3時間で消える前に）」が起こりそうです。

- **案2**：付け替えは作らない（削除→置き直し）。
- 技術メモ：2つの表をまたぐので、中身（ファイル）を別のバケットへ移す必要があり、移動中に失敗すると片方に残る可能性があります（作りは可能）。**送付用→社内は有用、社内→送付用は需要が小さい**と見ています（片方向だけでも可）。
- 確認したいこと：付け替えを作るなら、残り時間は「移した時点から数え直す（14日／3時間）」でよいか。

## 3. 画面下のエクスプローラー風「一時ファイル」の引き出しの扱い
`sample-39-explorer-drawer.png` ＝ 取っ手バーから開く、Windows のエクスプローラー風の画面（詳細／アイコン表示・複数選択・F2で名前変更・ドラッグ取り出し・検索など）。新画面の入口（⑤の枠・合計バー）は「案件のファイル」の一覧に切り替えたため、**この引き出しへは新画面からは入れなくなりました**（旧画面と、Code 側の関数からは今も開けます）。
- **案a**：引き出しは廃止して、機能を「案件のファイル」に寄せる（名前変更・複数選択のダウンロード・検索は「案件のファイル」の一覧には無い）。
- **案b**：引き出しを残し、「案件のファイル」の見出し行に［エクスプローラー表示で開く ▸］のような入口を足す（大量のファイルを扱う人向け）。
- **案c**：引き出しは残すが、新画面では出さない（今の状態）。
- Code の見立て：使う人の大半は一覧で足りるはず。**案cのまま様子を見て、必要なら案b**が低リスクです。

## 4. ［その他 ▾］の整理とボタン名（Design 36・37 で保留にした分）
`sample-39-row-detail.png` ＝ 明細1行の［その他 ▾］を開いたところ。設定ボタンが13個（単価の扱い6／計算のしかた5／適用の条件2）で、押すまで何も起きない（下の説明バー「ボタンを押すと、ここに説明が出ます」）。新人・実務者のレビューで挙がった点：
- **よく使うものを先に**：［あえて¥0］［MIN］［幅］［%］くらいが実務の大半。残りは［さらに ▾］の奥へ、でよいか。
- **ボタン名の言い換え案**（略語で意味が分かりにくい）：
  | いま | 案 |
  |---|---|
  | あえて¥0 | 0円で載せる |
  | PS | PS（ピーク時割増）※用語集の名前に合わせる |
  | MIN | 最低料金 |
  | 幅 | 金額の幅（〜） |
  | 売値ベース | 売値から逆算 |
  | 必要時 | 必要なときだけ |
  | 参考 | 参考料金（請求しない） |
  | 概算 | 概算（変わることがある） |
  合計バーの［数量登録］［参考 ▸］は、1500px以上では出ない（右レールに常時表示）ので、1500px未満だけの名前です。［数量登録］→［数量をまとめて変更］、［参考 ▸］→［似た案件・資料 ▸］のような言い換え案。
- 確認したいこと：言い換えると、**既存の画面の説明・用語集・過去のスクリーンショットと名前がずれる**ため、どこまで変えるか（全部／よく使う4つだけ／変えない）。
- 注意：行の高さ・列幅は変えない前提（Industry の3段固定）。名前を長くすると［その他 ▾］の中で折り返す。
