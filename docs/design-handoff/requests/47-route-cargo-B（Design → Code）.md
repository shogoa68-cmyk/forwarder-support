# 47 ステップ②ルート・③貨物・物量：決定（Design → Code）

**案B（①とそろえる）**。共通の決まりは 00-common-layout-B.md。画面案：reference/Route Cargo Options.dc.html（②／③・案B）。案（パターン）タブとの連動（案ごとに貿易条件・物量・コンテナを持つ）は崩さない。右の列の見出しは「この案の条件」で、案のタブを切り替えると右の列の値も変わる。

## ② ルート
### 左の列
1. 貿易条件・方向・モードが**未選択のときだけ**、今の順に開く選択（cond-flow）を左の列の頭に出す。選び終わったら隠れて右の列の行へ。
2. **POL → POD の点の流れ**（幹線輸送の枠・見出しはやめる）：
   - 行：点｜国（170px）｜港（340px）。POL の下に［＋ 経由地を追加］（文字リンク）、POD。インドのときだけ ICD。
   - 出発地側・到着地側を ON にしたときだけ、POL の上に「集荷地」、POD の下に「配送地」の欄が出て、点の流れがつながる。
   - 国の説明文は**1行に短く**、該当するときだけ：「🌐 登録済みの港がない国です。港名を入れると登録を申請できます。」
3. キャリア（船会社）任意：欄名に見出しを付ける（340px）。欄名の行の右端に**「🔗 ONE のリンク ▾」**（キャリアのリンクの札7つ＝スケジュール・追跡・CY-CUT・輸入SC・輸出SC・FT照会・航路 をこの中へ）。
4. サービス名｜T/T（2列・任意）。
5. 文字リンク：［＋ 役割・実運送人］［＋ 別の航路を登録（案を比べる）］（今の［＋ 航路］の名前を変える）。登録した航路のチップはこの下（今どおり）。
- ［＋ キャリア・サービス名・T/T（任意）］で畳むのはやめ、常に出す（3つとも短い欄のため）。
### 右の列「この案の条件」
| 行 | 操作 |
|---|---|
| 貿易条件 | ▾ |
| 方向 | ▾ |
| モード | ▾ |
| 荷役条件（RO/RO・在来船のときだけ） | ▾ |
| 出発地側 | スイッチ（OFF＝灰「使わない」） |
| 到着地側 | スイッチ |

### 移すもの
- **「🔧 ゾーン構成から見積もり行を生成」［この構成でプリセット適用］は ④ 費用へ**（費用の表の上・行を作る操作の近く）。

## ③ 貨物・物量
### 左の列
1. 貨物名（列いっぱい）。
2. HS コード（240px）。欄名の行の右端に「WEBタリフ ↗」（文字リンク）。
3. **FCL のとき**：
   - 見出し「コンテナ」（14px 太字）＋灰「FCL（種類 × 本数）」、右に「❄️ 特殊コンテナ ▾」（今のタブの代わり。特殊を選んでいる案では特殊が先）。
   - 20'GP／40'GP／40'HQ／45'HC／未定 を5つ並べ、−0＋（32px）。1本以上のものは枠を主色に。
   - その下に「荷姿・貨物明細　任意（FCL）　▸ 開く」＋1行の合計「R/T 0.000 ・ CW 0 kg ・ CBM 0.000」。開くと**その場で**表が出る（今の「詳細」の帯は、コンテナの上でなく荷姿の見出しのところに）。
4. **LCL・航空のとき**：荷姿・貨物明細の表が先（開いた状態）。コンテナは出さない（今の切り替えはそのまま）。
### 荷姿の表まわり
- 表の上の右端：「☐ サイズ・重量が不明」。
- 表の中の「輸送モード（指定なし）」は②のモードと同じなので外す（違うモードを試すときは比較案から）。
- 表の下：［＋ 荷姿を追加］（表の最後の行の文字リンク）。
- 合計の行：「R/T 5.808　CW 1,400 kg　CBM 5.808」＋［→ 費用に数量を入れる ▾］（今の［→見積］3つを1つに。中で R/T／CW／CBM を選ぶ）＋［⋯］。
- ［⋯］の中：📋 テキストでコピー ／―／ 🧊 バンニングシミュレーター ／ 🔲 パレタイズシミュレーター ／―／ ＋ 別パターンを作成 ／ ⧉ 複製して作成 ／ VS FCL/LCL 比較案を作成。紫・紺の濃いボタンはやめる。
### 右の列「貨物の区分・確認」
| 行 | 操作 |
|---|---|
| 危険品・特殊 | ▾（今の［⚠️ 危険品・特殊貨物 ▾］） |
| 関税率 | ▾（今の［％ 関税率 ▾］） |
| 関連知識 | ›（今の［📚 関連知識・他法令 N ▾］・件数を値に） |
| この案 | 値＝案の名前、▾ で比較案の作成 |
### 消すもの・移すもの
- 見出し「📦 貨物情報」「貨物名・品目」「📦 物量情報」と要約の帯はやめる（見出しは本文の見出し＋「コンテナ」「荷姿・貨物明細」の2つ）。
- **［貨物・ルートの入力をクリア］は本文の見出しの右の［⋯］の中**（赤字・いちばん下・uiConfirm）。荷姿の［⋯］の最後にも同じもの。

## スマホ
- 右の列は左の列の下へ。
- ② 国と港は縦に2段（国→港）。
- ③ コンテナは2列の格子（−0＋ は 44px）。荷姿の表は1行＝1枚のカード（荷姿・個数・寸法・重量・段積み）。

## Code への確認
1. 出発地側・到着地側を ON にしたとき、集荷地・配送地の欄を左の列の点の流れに入れてよいか（今の帯の中身を移す）。
2. 特殊コンテナのタブを「❄️ 特殊コンテナ ▾」に変えても、案ごとの切り替えが保てるか。
3. ゾーン構成を ④ に移すとき、④ の表の上に置き場があるか。
