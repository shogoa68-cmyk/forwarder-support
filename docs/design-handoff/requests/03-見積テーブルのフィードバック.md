# Design へのフィードバック：見積テーブル（見積入力画面の明細表）の改善 7 件

実画面（Industry テーマ適用中）を使って気づいた点です。画像は同梱（`images/fb1〜fb7`）。
**CSS だけで足りるものは CSS で、HTML／JS の変更が必要なものは「必要な構造」を明記してください**（これまでと同じ進め方）。

## 守ってほしい条件（これまでと同じ）
- `id`・`onclick`・`data-*`・JS が付け外しする class は残す。機能の廃止はしない（表示の整理のみ）。
- 隠した項目も DOM に残す（保存・計算は継続）。
- 見積テーブルは「詳細表示」「かんたん表示」の両方で使われる。両方で崩れないこと。
- 客先向けの出力（御見積書・メール・プレビュー）は今回の対象外。ただし **文言を変える場合は、出力側の同じ語も揃える必要があるため、候補として挙げてください**（code 側で出力との整合を確認します）。

## 1. 数量と単位が横並びになり、単位名が切れる
**画像：`fb1-qty-unit.png`**
- 現状：`td.qty-cell > .qty-wrap` で数量 `.w-qty` と単位 `.w-unit` が横並び。単位の入力欄が狭く、`40'GP/…` のような長めの単位名が途中で切れる（画像は 2 行とも）。
- 要望：単位名が切れないようにしたい。
- 参考：単位は `datalist#unit-list` から選ぶほか、自由入力もできる（`40'GP`、`CBM`、`R/T`、`B/L`、`shipment` など。自由入力では長い名前も入る）。
- お願い：数量と単位の幅の配分（または、縦積みに戻す／単位だけ折り返す等）の案。**単位の列の幅を決めて**ください。

## 2. 仕入れ・乗せ幅・売値の欄の大きさを統一
**画像：`fb2-price-fields.png`**
- 現状：「仕」（仕入れ `pp`）と「＋」（乗せ幅 `mk`）は枠付きの入力欄で同じ大きさ。「売」（売値 `bp`）だけは枠のない表示（点線の下線）で、大きさ・見た目が違う。
- 要望：3 つのサイズ（幅・高さ・文字の大きさ）を統一したい。
- 注意：売値は**表示専用**（`readonly`・`tabindex=-1`・`.display-field`）。入力欄に見えると「ここに入力できる」と誤解されるため、**枠の有無で入力可／不可を区別するか、大きさは同じで見た目だけ表示用と分かる形**にしてください。

## 3. 明細行にカーソルを乗せたときのフラグ群：文言変更と「登録」ボタンの移動
**画像：`fb3-row-mode-btns.png`**
- 対象：`td.price-cell` の `.row-mode-btns`（行ホバーで出る）。
- **文言の変更**（要望）：
  - 「¥0✓」→ **「あえて¥0」**（`.zero-confirm-btn`。ON 時のバッジ `.zero-confirmed-badge`「¥0 ✓」も同じ語に揃えたい）
  - 「都度」→ **「必要時」**（`.cond-charge-btn`。説明文の「発生時のみ／必要時のみ請求」「参考情報（都度…）」の記述も揃える）
- **「登録」ボタンの置き場所**（要望）：`.master-reg-btn`（「📥 登録」＝この行をマスター登録）と `.master-detail-jump-btn`（「📇 詳細」＝マスター詳細へ移動）は、他のボタン（¥0・実費・PS・必要時・参考・概算・%）とは**性格が違う**（他は明細の種類を示すフラグ、これは別の操作）。**明細名フィールドの隣などに別に置く**案がほしい。
- お願い：（a）フラグ群の並びと、ラベルの文字数が増えても崩れない見せ方、（b）「登録／詳細」の置き場所・見た目・呼び名（「マスター登録」または「詳細」）の案。
- 注意：「登録」は品名が入っているときだけ意味がある、「詳細」はマスターに登録済みのときだけ表示される（`hidden` 切替）。この出し分けは残す。
- 補足：客先向け出力側にも「都度請求」の語があるため、「必要時」への変更範囲は code 側で整合を確認します。

## 4. つまみ付近のメニュー：表示の揃え・ちらつき・チェックボックスとの重なり
**画像：`fb4-handle-menu.png`、`fb5-handle-menu-tree.png`**
- 対象：`td.handle-cell` の `.row-acts`（👁🔍✓➕📋🗑️）。
- 現状：行にカーソルを乗せると、**つまみ（⠿）が上に移動して**アイコンのメニューが現れ、**レイアウトが動いて「ちかちか」する**。また、メニューが**行選択のチェックボックスと重なる**。
- 要望：
  1. メニューの表示を、フラグ群（実費・必要時など）と同様に**文字ラベル付き**にする。
  2. **ホバーで行のレイアウトが動かない**ようにする（ボタン領域を常に確保する、またはホバー時だけ上に重ねる等）。
  3. チェックボックスと重ならない配置にする。
- お願い：つまみ・チェックボックス・操作ボタンの**配置の案**（かんたん表示でも同様）。アイコンのみの現状から、ラベルを付ける場合の**幅と省スペース案**もほしい（列が狭いため、アイコン＋短い文字、またはホバー時のツールチップ等の選択肢）。
- 注意：各ボタンの機能（見積書に出さない／要調査／入力完了／直下に追加／複製／削除）は変えない。

## 5. サブコン名の入力欄に線がかぶる（ツリーの名残）
**画像：`fb5-handle-menu-tree.png`（左下の「SITC」）**
- 現状：`td.catsv-cell` の `.w-subcon` の上に、「└」状の線が重なって表示される。
- 原因の見当：`tr.subcon-child .catsv-cell::before`（サブコン別グループの階層線＝ツリー表現）。Industry の 3 階層表示（サブコン › パターン › カテゴリ › 明細）で別の階層表現ができたため、この線は不要になっているはず。
- 要望：この線を**削除**する（階層は見出しの帯と左の階層線で表現済みのため）。
- お願い：不要な階層線の整理（`tr.subcon-child`・`tr.subcon-subchild` の `::before` ほか）。

## 6. サブコン別見出し行（折りたたみ時）：操作の左寄せと金額の右揃え
**画像：`fb6-subcon-header.webp`**（実データのサブコン名・金額を含みます）
- 対象：`tr.subcon-group-header`。
- 現状：行にカーソルを近づけると、行の**右側**（金額の右）に「含む」「＋」「更新」「日付」「今日」などの操作が出る。金額（¥354,400※ など）は行の**中ほど**に置かれている。
- 要望：
  1. 行にカーソルを近づけると出る**操作を左寄せ**にする（サブコン名のすぐ近くに）。
  2. **合計金額を右揃え**にする（行の右端）。
- お願い：見出し行の左（つまみ・矢印・チェック・名称・行数）／中（操作）／右（金額）の配置案。パターン見出し・カテゴリ見出しとの整合も。

## 7. 一番下の全体合計の行が小さく目立たない
**画像：`fb7-total-row.webp`**（実データの金額を含みます）
- 対象：`tfoot` の合計行（`tr.tot-row`）。
- 現状：「合計（JPY 換算）」の行が、小さな文字・薄い背景で控えめに並ぶ。仕入・売値・粗利の金額が目立たない。
- 要望：見積全体の合計なので、**もっと目立たせる**。
- お願い：サイズ、背景、強調（売値＝客先に出す金額を最も強く、仕入・粗利は副次的に）の案。**粗利率がマイナスのときの警告表示**（`.profit-neg`）も含めて。
