### 3. 航路の一覧：カード・「採用」1 つ（ユーザー合意済み）
- 1 航路を 1 枚のカードにしました。
  - 見出しの行：⠿・案の名前（無いときは「案名なし」＋［＋ 名前］）・採用の札・往路／復路・［採用にする］［✎ 直す］［⋯］
  - 2 行目：「キャリア · POL → 経由 → POD · T/T」
  - 区間：縦の点の流れ（海上だけ主色）。無いときは［＋ 区間を足す］
- 札と見た目は回答のとおりです：採用＝緑の枠＋左に 3px の線＋「✓ 採用」／不採用＝60% の薄さ＋取り消し線の札／未定＝札なし。使用不可は赤い札です（押すと理由を直せます）。
- ［⋯］の中：案の名前・区間・未定に戻す／不採用にする・使用不可にする（解除する）・上へ／下へ・削除。
- 一覧の見出し：「航路」＋「N 本 ・ 見積書に出すのは『採用』の 1 本」＋［＋ 航路を追加］。
- 入力欄：航路が 0 本のときは今までどおりです。1 本以上あるときは畳み、［＋ 航路を追加］で一覧の下に点線の箱を開きます（［この航路を登録］［キャンセル］）。［✎ 直す］は、同じ箱をそのカードの場所に開き、その場で書き換えます。
- **採用が見積書に出す航路を決めます。** 採用は 1 本だけで、別のカードを採用にすると、前の採用は未定に戻ります。1 本しかないときは自動で採用です。
- **回答に無かった点（往復の案件）**：採用は往路・復路で 1 本ずつです。往路／復路を指定していない航路は、従来どおり 1 本目＝往路・2 本目＝復路として、2 本まで採用できます。見出しの説明も「（往路・復路で 1 本ずつ）」に変わります。
- 物量パターン（FCL案／LCL案など）ごとに、別の航路を採用できます（今までの「使う ✓」の覚え方のまま）。

## 2. 確認（回答の 8）への答え
1. **「使う ✓」が 2 本以上付いている見積**：本番のデータは Code から数えられません（読む口がありません）。ユーザーの決定で、**開いたときに一番上の 1 本を採用**として扱います（往復は往路・復路ごと）。ほかの航路は「未定」に戻り、見積書には出なくなります。
2. **列のオン／オフの記憶**：端末ごとです（PC とスマホは別々）。
3. **解除の確認の件数**：すぐに数えられます。読み込み済みの案件から数えるので、通信は増えません。
4. **旧いサブ案件を開いたときの上のバー**：もともとメインへ戻る表示はありません（今回も足していません）。メインへは、ダッシュボードのカードの「🔗 関連 N件」から移れます。上のバーに「🔗 関連 N件」を出すかどうかを決めてほしいです（下の 3-2）。

## 3. 決めてほしいこと
1. スマホのプレビューの［閉じる］を、印（✕）だけにしてよいか。題名が「📋 プレ…」と省略されるのはよいか。
2. 編集画面の上のバー（案件名の横）に「🔗 関連 N件」を出すか（押すと関連の一覧）。
3. ☆ の 1 つめの文言「☆ 登録（自分の分だけ）」でよいか。
4. 航路のカードで、「不採用」と「使用不可」の違いが分かりにくくないか（いまは、不採用＝薄く・取り消し線の札／使用不可＝赤い札）。
