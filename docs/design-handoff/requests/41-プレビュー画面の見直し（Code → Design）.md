# プレビュー画面（表計算・見積書・PDF 出力設定）の見直し（Code → Design）

2026-11-18。新画面・Industry・1440px／390px で、上のバーの［📋 プレビュー］と［📄 PDF 出力］を開いて確かめました。明細は 4 サブコン・6 行（USD と JPY が混在）。画像は `sample-41-*.png`。

## 0. いまの作り（前提）
- ［📋 プレビュー］＝ `#previewOverlay`。左のレールで**レイアウト**（📋 表計算／📄 見積書）と、表示する列・セクションのスイッチ。右上に［📄 御見積書］［✉️ メール本文］［📊 Excel（表計算のときだけ）］［🖨️ 横｜縦］［閉じる］。
- ［📄 PDF 出力］＝ `#quoteDocOverlay`（別の画面）。左に御見積書、右に暗い「PDF 出力設定」（ファイル名・英語で出力・英訳辞書・合計を非表示・図解・パターン併記・出力後に提示済みへ・発行元・用紙・［PDF 出力（印刷）］［閉じる］）。
- どちらも、開く前に「出力前の確認ガイド」（`#pvWarnGuide`）が出ることがある。

## 1. 問題（大きい順）

### A. 社外に見せる画面に「仕入・粗利」が出たまま（事故の危険）
- プレビュー・御見積書の画面の**上に、下の合計バー（売・仕入・粗利 7.6%）と❓が重なって出ている**（全画像の最下部）。御見積書を画面共有でお客様に見せると、仕入と粗利が見えてしまう。
- 表計算の「社内用－客先送付不可」の透かしは良いが、御見積書の画面には何も無い（社外用なので正しい）。その画面に社内の数字が重なるのが問題。
- 案：**プレビュー・PDF 出力の画面を開いている間は、合計バー・❓を出さない**（Code ですぐ直せる。先に直してよいか）。

### B. 「見積書」が 2 か所にあり、見た目も違う
- プレビューの［📄 見積書］（`sample-41-preview-doc.png`）と、［PDF 出力］の御見積書（`sample-41-quotedoc.png`）は**同じ書類のはずなのに、見た目が違う**：
  - プレビュー側は、用紙の**余白がなく**枠にくっつく／品名・数量・単位が**中央寄せ**／見出しが用紙の外にはみ出る（宛先・挨拶文が左端ぴったり）。
  - PDF 出力側は、余白ありで品名は左寄せ（こちらが正しい体裁）。
- さらにプレビューの右上の［📄 御見積書］を押すと、PDF 出力の画面が開く（見ていたものと同じ名前のものが別に開く）。
- 案：
  - **案1**：プレビューの［📄 見積書］レイアウトを廃止。プレビュー＝社内確認（表計算）、PDF 出力＝客先向けの御見積書、と役割を分ける。
  - **案2**：残すなら、PDF 出力と同じ見た目（余白・左寄せ）にそろえ、右上の［📄 御見積書］は「PDF 出力の設定を開く」に名前を変える。
  - Code の見立て：案1 が分かりやすい（「見積書を見たい＝PDF 出力」に一本化）。

### C. 見出しが食い違う
- 見積書レイアウトのとき、左のレールは「📋 プレビュー（御見積書フォーマット）」、右の見出しは「📋 プレビュー（表計算形式）」のまま（`sample-41-preview-doc.png`）。左の見出しは 2 行に折り返す。
- 案：見出しは右の 1 か所にし、選んだレイアウトに合わせる。

### D. 出力前の確認ガイドが、PDF 出力設定の上に重なる
- `sample-41-gate-over-panel.png`：確認ガイド（粗利率が低い・為替が古い）が、PDF 出力設定の「発行元」「用紙」「PDF 出力（印刷）」の上に重なり、押したいボタンが隠れる。
- 案：ガイドは**御見積書の上（用紙の上端）に帯として出す**、または PDF 出力設定のパネルの中の先頭に入れる。

### E. 表計算（`sample-41-table.png`・`sample-41-table-bottom.png`）
- **列が 17**。「数量・通貨・単価」が 2 回出る（仕入と請求）が、見出しに「仕入」「請求」のまとまりの名前が無い。色（茶・緑・灰）の意味の説明もない。
  - 案：見出しを 2 段にし、上の段に［項目］［仕入］［請求］［結果］のまとまり名。
- カテゴリが未設定の行は全部「— カテゴリ —」と出る（意味のない文字が並ぶ）。→ 空欄でよい。
- CD 列が全部「0」。→ 0 は薄く、または空欄。
- 小計行（黄土色）に「↳ 小計 仕入合計 ¥450,000※ 粗利率 6.3%」がぎっしり詰まり、背景の色が濃い。→ 背景を薄く、仕入合計・粗利率は右の対応する列に入れる。
- 合計の行が 3 つ（JPY・USD・≈JPY）。≈JPY が本当の合計なのに、太字は少し太いだけ。→ 合計（≈JPY）を目立たせ、通貨ごとの行は小さく。
- 下の注記（「* CSV はデータ行のみ出力…」）は、CSV ボタンがこの画面に無いのに出ている。

### F. 御見積書の中身（`sample-41-quotedoc.png`・`-bottom.png`）
- カテゴリ未設定のとき、**「— カテゴリ —」という空の見出し行がお客様向けの書類に出る**。→ 出さない。
- 数量が「2.0000」（小数 4 桁）。→ 整数は「2」、小数は必要な桁だけ。
- 単価「1,300.00 USD」が 2 行に折り返す（列が狭い）。→ 単価の列を広げるか、通貨を見出しへ。
- サブコン名（ONE・横浜港運・A通関・B運送）が見出しにそのまま出る。客先表示名を入れれば変えられるが、**既定が下請けの実名**。→ 既定で出すか、出さないか（方針の確認）。
- 免税の行だけのとき、「課税対象小計 ¥0」「消費税（10%）¥0」の 2 行が残る。→ 0 のときは省くか。
- 為替の注記（「為替：手動設定値…」）が小さく薄い。外貨の行があるときは大事な情報。

### G. PDF 出力設定（右の暗いパネル）
- 設定が縦に 7 つ並び、**［PDF 出力（印刷）］が「用紙」の下で、画面の下端ぎりぎり**（低い画面ではスクロールが要る）。
- ［📖 英訳辞書］が、スイッチの並びの中に挟まって見える（ボタンかスイッチか分かりにくい）。
- 「パターンを併記」が薄く押せないが、理由が出ない（パターンが 1 つのとき）。
- 案：①上に［PDF 出力（印刷）］（主ボタン・固定）②よく使う設定（英語・合計を非表示・図解）③そのほか（パターン併記・提示済みへ・発行元・用紙）の順。

### H. スマホ（390px）
- `sample-41-phone-doc.png`：プレビューは、左のレールが上に積まれて、本体が画面の下へ押し出される。見積書は縮まずに右が切れる（「LOS ANG…」）。下の合計バーが上に重なる。
- `sample-41-phone-table.png`：開くと**スイッチの一覧が画面いっぱい**で、表が見えない。
- `sample-41-phone-quotedoc.png`：PDF 出力は設定パネルだけが出て、**御見積書そのものが見えない**。
- 案：スマホでは、①書類（または表）を先に・画面幅に縮めて出す ②設定・スイッチは［⚙ 設定］ボタンで下から出るシートへ ③下に［PDF 出力］［閉じる］だけ。

### I. その他
- 発行日・有効期限の入力欄がプレビューの中にもある（①基本と 2 か所）。プレビュー中に直せるのは便利だが、「ここで変えると元の欄も変わる」ことが分からない。→ 「① 基本と同じ値」と小さく添えるか。
- ボタンの並び（［御見積書］［メール本文］［Excel］［🖨️ 横｜縦］［閉じる］）が、上のバー（［プレビュー］［PDF］［保存］）と順番・強さが違う。

## 2. 決めてほしいこと
1. A：プレビュー・PDF 出力の画面では合計バー・❓を出さない（Code で先に直してよいか）。
2. B：プレビューの「見積書」レイアウトを廃止（案1）か、そろえて残す（案2）か。
3. D：確認ガイドの出し方（用紙の上の帯／パネルの先頭）。
4. E：表計算の見出しを 2 段（まとまり名）にする案。
5. F：御見積書のサブコン名を既定で出すか。0 円の税の行を省くか。数量の桁。
6. G：PDF 出力設定の並び（主ボタンを上へ）。
7. H：スマホの組み方（書類を先に・設定はシート）。

## 3. 制約
- 既存の DOM・id・onclick・出力の中身（PDF・Excel・メール）は、F の項目以外は変えない。F は**お客様に渡る書類が変わる**ので、Design の確認後に変える。
- 3 テーマで崩れないこと。印刷（PDF）の見た目は画面と同じにそろえる。文字は 12／13／14／16／18px（御見積書の中は対象外）。
