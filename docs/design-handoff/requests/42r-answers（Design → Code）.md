# 42 実装の報告への返事と、4つの答え（Design → Code）

「42『残りの決めごと』：実装の報告と確認への答え」への返信です。実装ありがとうございます。

## 0. 報告への返事（すべてそのままでよい）
- 1 プレビューの列：CD を別のスイッチに分けたこと・Excel/CSV を変えていないこと・≈¥ の重ね出しをしないこと、すべてよい。
- 2 スマホのプレビュー：Esc で ⋯ だけ閉じる動き、よい。題名は下の 1 で直す。
- 3 航路：**往復の案件は往路・復路で1本ずつ採用**、物量パターンごとに別の採用、どちらもよい。「使う ✓」が2本以上の見積は**開いたときに一番上の1本を採用**、で確定（ユーザー決定どおり）。
- 4 マスター：解除の確認を PC にも入れたこと・新規登録のシート中に ❓ を隠すこと、よい。通知を上にそろえることを**スマホの全画面で共通**にしたこと、よい。
- 6・7：報告どおりでよい。
- 2-4（旧いサブ案件からメインへ戻る表示）：下の 2 で答えます。

## 1. スマホのプレビューの題名：**2行目へ移す**
- 上の行（56px）は**ボタンだけ**：［⚙ 設定］［⋯］［📄 PDF 出力］（主）［✕］（44px）。左に寄せず、右寄せでもよい（左端の余白 12px）。
- 題名は、すぐ下の要約の行の頭へ：「**プレビュー** · 99-261123-001 · 山田商事 · 有効 11/30」（13px・題名だけ太字・1行で…省略）。
- ✕ だけの閉じるボタンは**そのままでよい**（title と読み上げで「閉じる」）。

## 2. 上のバーの「🔗 関連 N件」：**出す**
- 関連が **1件以上のときだけ**、案件名の右の状態の札（下書き中など）の、さらに右に小さな札「🔗 関連 N件」（12px・灰の面・押せる見た目＝ホバーで枠）。0件のときは出さない。
- 押すと、右レールの「類似」の引き出しが開き、上の「🔗 関連付けた案件」が見える（関連の一覧）。
- 旧いサブ案件を開いたときも同じ（メインへはこの一覧から移れる）。メイン／サブの区別は出さない（7 のとおり「関連」1種類）。
- スマホ：上のバーには出さず、［⋯］の中に「🔗 関連 N件」を1行（44px）。
- N は、ダッシュボードのカードの「🔗 関連 N件」と同じ数え方（メイン・サブ・孫・ただの関連をまとめて）。

## 3. 統計のスマホの ☆：**「☆ 自分の1票を入れる」**
- 下から出る2択のシート：
  1. **☆ 自分の1票を入れる**　下に小さく（12px 灰）「票が集まると、マスターに入れる候補になります」
  2. **☆ マスターに登録（チームで使う）**　下に小さく「すぐにチームの候補に出ます」（権限がない人には出さない／押せない理由を1行）
- 1票を入れ済みのときは、1 の名前を「★ 1票を入れています（取り消す）」に。
- PC の文言も、次に触るときにこの言い方へそろえてよい（PC の「☆ 登録」→「☆ 1票を入れる」）。

## 4. 航路の「不採用」と「使用不可」：**使用不可に理由を添え、採用できなくする**
| | 意味 | 見た目 | 操作 |
|---|---|---|---|
| 不採用 | 自分で選ばなかった | カード 60% の薄さ＋灰の札「不採用」（取り消し線はやめる） | ［採用にする］を出す |
| 使用不可 | 使えない（満席・休航・条件外など） | 赤い札「🚫 使用不可」＋2行目の下に理由1行（12px・赤寄りの灰）、カード 60% の薄さ | **［採用にする］を出さない**。［⋯］に「使用不可を解除」「理由を直す」 |
- 使用不可にしたカードが採用中だったら、採用を外して「未定」に戻し、トースト「採用を外しました（使用不可のため）」。
- 理由が空のときは「理由：未入力」と灰で出し、押すと理由の欄が開く。

## 5. 画像を見て気づいたこと
- スマホの②（sample-42r-route-cards-phone.png）で、右下の ❓ が航路のカード（［✎ 直す］［⋯］の下）に重なっている。下の固定の帯（合計・ボタン）の**上の余白の中**に ❓ を置くか、本文の下に ❓ の分の余白（56px）を足してほしい。
- 同じ画像で、②のスマホの頭に「インコタームズ」の選択が出ている（未選択のため）。これは 47 の「未選択のときだけ左の列の頭に出す」どおりなのでよい。
