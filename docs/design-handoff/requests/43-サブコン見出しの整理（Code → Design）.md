# 見積もりテーブルの「サブコン見出し」の整理（Code → Design）

2026-11-19。新画面・Industry・1440px。明細を 3 サブコン・5 行で並べて撮りました。画像は `sample-43-*.png`（`-user` はユーザーの実画面・社名は塗りつぶし済み）。

## 0. いまの見出し（1 行に最大 16 個の部品）
左から：⠿（並べ替えのつまみ）・▼（開閉）・☐（まとめて選ぶ）・📦 サブコン名（客先表示名の欄を兼ねる）・「3 行」・マスターの印（⚠ 未登録／📨 申請中）・📇 詳細・役割の札（FCL CARRIER など）・🔖 BOOKMARK・📥 取り込み・📝 注記（入力欄＋「📄 見積書に表示」）・仕入 ¥…・粗利 …%・「除外」・［＋ 明細を追加］・［⇅カテゴリ］・売値小計（右端・大きい）。
- 注記の入力欄は、空のときマウスを乗せるまで隠れます（`sample-43-header-normal.png` と `-hover.png` の違い）。

## 1. 問題
1. **部品が多すぎて、どれが大事か分からない**（名前・金額・明細を足す、の 3 つが埋もれる）。
2. **注記の入力欄が「仕入・粗利」の文字に重なる**ことがある（`-user.png`）。← 不具合なので、Code で先に直してよいか。
3. ［＋ 明細を追加］（いちばん使う）が、ほかのボタンと同じ見た目で並んでいる。
4. **「除外／含む」の名前**：除外中のグループのボタンが「含む」（＝押すと何が起きるか）になっていて、「いま含まれている」と読めてしまう（`-excluded.png`）。
5. 金額が左右に分かれる（仕入・粗利は中ほど、売値小計は右端）。合計行（売・仕入・粗利）とまとまり方が違う。
6. 役割の札（FCL CARRIER）がボタンに見える。
7. ［⇅カテゴリ］（カテゴリ順に並べ替え）はめったに使わないのに、常に出ている。

## 2. 案
- **A（2 段）**：上段＝名前・行数・役割の札・金額、下段＝操作のボタン（注記・取り込み・詳細など）。分かりやすいが、見出しが倍の高さになり表が縦に長くなる。
- **B（1 段＋［⋯］）＝ Code のおすすめ**：
  - 常に出す：⠿ ▼ ☐ ／ 名前・行数・役割の札（札は枠なしの文字） ／ 右にまとめて「売 ¥580,000　仕入 ¥540,000　粗利 6.9%」 ／ ［＋ 明細を追加］（主ボタン） ／ ［⋯］
  - ［⋯］の中：📥 取り込み ／ 📇 詳細 ／ 🔖 BOOKMARK ／ 📝 注記を書く ／ ⇅ カテゴリ順に並べる ／ 見積書から外す（除外中は「見積書に戻す」）
  - 注記が入っているときだけ、名前の横に「📝」の印（押すと注記の欄が開く）。
  - マスター未登録・申請中の印は今どおり名前の横に常に出す（気づいてほしいので）。
  - 除外中：見出しと行を薄くし、「見積書から外しています」の札＋［見積書に戻す］を出す。
- **C（名前を押すとポップアップ）**：名前を押すと操作の一覧が出る。部品はいちばん減るが、名前の欄は客先表示名の入力も兼ねているので、押したときの動きがぶつかる。

## 3. 決めてほしいこと
1. A／B／C のどれにするか（または別案）。
2. ［⋯］の中に入れる項目と順番。BOOKMARK・詳細はマスター登録済みのときだけ出ます。
3. 注記（客先表示名・サブコンへの注記）の入力欄をどこに置くか（［⋯］から開く小さな欄／見出しの下にもう 1 段 など）。
4. 除外中の見せ方と、ボタンの名前（「見積書から外す／戻す」でよいか）。
5. パターン見出し（FCL案／LCL案などの 2 段目の見出し）も同じ作りにそろえるか。
6. 金額の並び（売・仕入・粗利の順・大きさ）。

## 4. 制約（いつもどおり）
- 既存の DOM・id・onclick・保存データは変えない（隠す・要素ごと移す・［⋯］から元のボタンを押す、だけ）。
- 3 テーマ（Industry／現行／Quiet）・旧画面でも崩れないこと。文字は 12／13／14／16／18px。タッチ端末は 44px。
- スマホ幅（〜600px）は、表の代わりに一覧（`#mcList`）が出るため、この見出しは出ません（対象外）。
