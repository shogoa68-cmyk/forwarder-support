## 3. 行の詳細（行の下に開く）
- 開き方：行の何もない所を押す／行にフォーカスして Enter／［⋯］→「行の詳細」。閉じ方：もう一度押す・Esc・ほかの行を開く。開くのは1行だけ。
- 実装：明細の `<tr>` の次に、表示専用の `<tr class="cost-detail">`（colspan で全幅）を差し込む（仮想の行と同じ扱い・保存・出力の対象外）。中の欄は、その行の既存の欄（id そのまま）を移して見せる。
- 中身（上から）：
  1. 見出し行：「{項目名} の詳細」＋右に［⧉ 複製］［✓ 入力完了］［削除］（赤字・uiConfirm）。
  2. 4列の欄（32px）：備考（社内用）／カテゴリ／課税／売の通貨。
  3. 「単価の扱い」：よく使う4つ＝［0円で載せる］［MIN］［幅］［%］（丸いチップ・選んでいれば主色）＋［さらに ▾（9）］。さらにの中は Design 36 の3グループ（単価の扱い／計算のしかた／適用の条件）と説明バーをそのまま。
  4. 貿易条件・表示条件・適用期間（今の［その他 ▾］の中のもの）も「さらに」の中。
- 左に 40px あけて、どの行の詳細か分かるように（背景 #fbfcfd・下に1px の線）。

保存データ・id・onclick は変えない（表示の出し分けと要素の移動）。明細の行は `<tr>` のまま（並べ替え・キー操作・貼り付け・Excel/PDF 出力が読むため）。仮想の行（見出し・小計・行の詳細）は表示専用。案（パターン）のタブ・入力完了の記録・％／MIN／幅の計算は変えない。旧画面はそのまま。3テーマ。文字 12/13/14/16/18px。

## 9. Code への確認
1. 行の詳細を `<tr>` の次に差し込む形で、並べ替え（ドラッグ）とキーボードでの移動が壊れないか（開いたまま並べ替えるときは閉じる、でもよい）。
2. 「⇄ 別のサブコンへ移す」は、今のサブコン欄の書き換えで実現できるか（パターン欄も一緒に移すか）。
3. 表の中の欄を 28〜32px にしても、キーボード操作・貼り付けに問題ないか（Design 40 の 36px の例外）。
4. 外貨の行だけ 48px になるのは許容か（そろえるなら全部 48px）。
