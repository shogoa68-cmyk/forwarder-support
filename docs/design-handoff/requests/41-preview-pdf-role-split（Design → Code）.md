# 41 プレビュー・PDF出力の見直し：決定（Design → Code）

画面案は reference/Preview Output Options.dc.html（案2を選んで見てください）。

## 決定：案2「役割を分ける」
- プレビュー（#previewOverlay）＝**社内確認の表計算だけ**。「見積書」レイアウトは廃止し、右上の［📄 御見積書］は「PDF 出力」への入口にする。
- お客様向けの御見積書は **PDF 出力（#quoteDocOverlay）に一本化**。

## 各項目
1. **A**：プレビュー・PDF出力を開いている間は、合計バー・❓を隠す（先に直してよい。閉じたら戻る）。
2. **C**：見出しは右の1か所（表計算になるので「📋 プレビュー（表計算）」）。左レールの2行折り返し見出しは出さない。
3. **D**：確認ガイドは**用紙の上に帯**で出す。PDF出力設定のパネルには重ねない。押したいボタンを隠さない。
4. **E（表計算）**：見出しを2段（項目｜仕入｜請求｜結果）、仕入＝茶・請求＝緑の見出し色と小さな凡例1行。カテゴリ未設定は空欄。CDの0は薄く／空欄。小計行は薄い背景で、仕入合計・粗利率は右の対応列へ。合計は≈JPYを大きく、通貨別は小さく。CSVの注記は消す。
5. **F（御見積書）**※お客様に渡る書類が変わる。確認後に変更：数量は整数「2」・小数は必要な桁だけ／空の「— カテゴリ —」行は出さない／0円の税行は省く／為替の注記は少し濃く／単価の列を広げ折り返さない／**サブコン実名は既定で出さない**（客先表示名を入れたときだけ出す）。
6. **G（PDF出力設定）**：①［PDF 出力（印刷）］を上に固定（主ボタン）→②よく使う（英語で出力・合計を非表示・図解）→③そのほか（パターン併記・提示済みへ・発行元・用紙・［📖 英訳辞書］）。パターンが1つのときの併記は、薄くして理由を小さく出す。
7. **H（スマホ）**：書類（または表）を先に、画面幅に縮めて出す。スイッチ・設定は［⚙ 設定］で下から出るシート（44px）。下は［PDF 出力］［閉じる］だけ。
8. **I**：発行日・有効期限の下に「① 基本と同じ値」と小さく添える。ボタンは副＝白地＋枠、主＝［PDF 出力］1つだけ。

## 制約
DOM・id・onclick・出力の中身はFの項目以外は変えない。印刷の見た目は画面と同じ。3テーマ。文字12/13/14/16/18px（御見積書の中は対象外）。

## Code への確認
- 「見積書」レイアウト廃止で、使われていた機能（列・セクションのスイッチ）が PDF出力側に必要か。
- 3種のボタン順（副→主）を保存画面と同じ考えにそろえてよいか。
