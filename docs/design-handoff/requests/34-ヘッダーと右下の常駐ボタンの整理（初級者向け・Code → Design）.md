# ヘッダーと「どの画面でも出続けるボタン」の整理のお願い（初級者向け・Code → Design）

2026-11-18。初級者（フォワーダー 1〜2 年目）の目線でアプリ全体を見たところ、「**いま自分はどこにいて、何を押せばいいか**が分かりにくい」という指摘が出ました。その中の **ヘッダー（上）と、画面に出続けるボタン（右下・下）の整理** だけに絞った依頼です。ナビ（上段のカテゴリ）の整理は別に済ませたので、今回は対象外です。

画像：`sample-34-header-floating-pc.png`（PC 幅 1440px）・`sample-34-header-floating-sp.png`（スマホ幅 390px）。**どちらも「ログイン前のダッシュボード」の実画面**です。ログイン後や見積入力画面の画像はまだ撮っていません（下の 1-3 は、コードで確認した一覧です）。

## 1. いまの構成

### 1-1. ヘッダー（上）
- 左：アプリ名「🛠️ フォワーダー支援」と 1 行の説明
- 右：**☰（メニュー）**と**アカウント**の 2 つだけ（以前は 5〜6 個のボタンが並んでいたのを 2 つにまとめた）
  - ☰ の中身：「ご意見・ご要望」＝🐞 不具合報告／💡 アイデア／📣 改修予定・アイデア、「表示」＝🎨 デザインの切替、さらに 🧭「見積入力：旧い画面／新しい画面」の切替
  - アカウント：ログイン前は大きな「Google でログイン」ボタン、ログイン後は丸いアバター（押すと 名前（プロフィール）／チーム管理（管理者だけ）／ログアウト）
- ヘッダーのすぐ下に、必要なときだけ帯が出る：📢 お知らせバー（管理者が出す）・🔄「新しいバージョンがあります」（古い画面を開いたままのとき）

### 1-2. どの画面でも右下に出続けるもの
- **🐞 常駐ボタン**（不具合・ご意見を送る）。初めて開いた人には、約 4 秒後に濃紺の吹き出し「不具合・ご意見はここから」と、赤い波紋・軽い揺れが出る（気づいたら以後ずっと出ない。気づかれなければ最大 3 回）。確認待ちの質問が来ているときは赤い数字の印も付く。

### 1-3. 見積入力の画面で、さらに出るもの
| 部品 | 場所 | 中身 | 旧画面 | 新画面 |
|---|---|---|---|---|
| 📝 案件名・社内メモ | 右下（スマホは丸 48px） | 付箋ウィンドウを開く | あり | あり |
| 保存／プレビュー／PDF の 3 ボタン | 旧＝右下のドック、新＝上のツールバー | 出力・保存 | 右下 | **上へ移動** |
| 合計バー | 旧＝浮かぶバー、新＝下に常時 | 売・仕入・粗利の合計（新は「数量登録」「パターン登録」「費用の内訳」「参考」も） | 浮かぶ | 下に固定 |
| 全体リマークの「取っ手バー」 | 画面の最下部 | 引き上げると全体リマーク・免責事項の欄が開く。気づかれないと 3 回跳ねる合図も出る | あり | リマークはステップ 5 の本文へ移り、取っ手は出ない |
| 右の引き出し | 右端 | 費用の内訳・比較・サブコンなどの切替（アイコンの縦の列） | あり | ボタンを押すと開く |

つまり**見積入力の旧画面だと、画面の端に常に 5〜6 個の部品が同時に出る**（🐞・📝・右下ドック・合計バー・下の取っ手バー・右の列）。この「同時に出る」状態の実画面の画像は、まだありません（必要なら撮ります）。

## 2. 困っていること

**コードと画像で確認できたこと**
- スマホ幅（添付画像）で、🐞 の吹き出しが**ログインのボタンの一部に重なって**、押したい場所を隠している。
- 「ご意見」の入口が ☰ の中で 3 つに分かれていて（不具合報告・アイデア・改修予定）、右下の 🐞 とも重なる。**同じ目的の入口が 4 か所**ある。
- ☰ の中身が「ご意見」「表示（デザイン）」「見積入力の新旧切替」と、**性質の違うものの寄せ集め**になっている。
- 「メモ」を書く場所が多い：案件名の欄／社内メモ（📝）／全体リマーク（下の引き出し）／明細の備考／サブコン別・パターン別リマーク。**何をどこに書けばいいか**が名前だけでは分からない。
- 新旧の画面で、保存ボタンなどの**場所が変わる**（右下 → 上）。手順書の写真と画面が合わなくなる。
- 「気づかせる」演出（🐞 の吹き出し＋波紋＋揺れ・取っ手バーの跳ねる合図）が**画面ごとに別々に**ある。

**初級者の目線での推測（実機での確認はまだ）**
- 画面の端に常に何かがあると、「押していいのか・何のボタンか」を考える手間が増える。
- ログイン前は大きなボタン、ログイン後は丸いアバター、と**見た目が切り替わる**ため、「どこからログアウトするのか」が分かりにくい。

## 3. お願いしたいこと

- **3 案くらい**（絵でも HTML でも可）。観点の例：
  - **A. 右下の常駐物をできるだけゼロに近づける**：🐞 を ☰ の「ご意見」に統合し、右下には出さない（確認待ちの赤い印だけ ☰ に残す）。気づいてもらう工夫は、別の形で（例：初回だけ ☰ に 1 度だけ印を付ける）。
  - **B. 右下は「ヘルプ・ご意見」のボタン 1 つだけ**：🐞 を、🐞 以外のヘルプ（使い方・用語集・ご意見）もまとめた 1 つのボタンにする。
  - **C. 画面ごとに出し分ける**：ダッシュボードでは右下は 0 個、見積入力では「保存」まわりだけ、というふうに、**いま必要なものだけ**を出す。
  - ☰ の中身の**並べ方**（目的ごとに「ご意見」「表示」「画面の切替」を分ける・見出しの付け方）。
  - **メモの置き場所**の整理（見た目だけでよい。「案件のメモ」「見積書に載せる文」「社内だけ」の区別が分かる見せ方）。
  - 初めて使う人への案内（吹き出し）を**どこに・何回**出すか。
- **優先して見たい状態**：①ログイン前 ②ログイン後のダッシュボード ③見積入力（旧画面）④見積入力（新画面）⑤スマホ幅 ⑥初めて開いたとき（🐞 の案内が出る）⑦確認待ちの質問が来ているとき（赤い印）
- 各案の**良い点・割り切り**を一言ください。
- 初級者向けの整理が目的なので、**用語は「やること」で書く**（例：「ご意見・不具合」「使い方」）案も歓迎です。

## 4. 守ってほしい制約
- **機能は消さない**（隠す・畳む・移すのは可）。既存の DOM・`id`・`onclick` を残して、CSS と薄い表示層で組み替える方針です（ヘッダーの ☰・アカウントも、元のボタンを**要素ごと移しているだけ**で、`cloud.js`／`users.js`／`feedback.js` は `id` のまま操作しています）。
- **3 つのテーマ**（現行／Industry（既定）／Quiet）の共通トークンで色を指定。文字は 12／13／14／16／18px（`--text-xs/sm/base/lg/xl`）。タッチの的は 44px 以上。
- 印刷（プレビューの印刷）では、これらの部品は出さない。
- **権限の違い**：チーム管理は管理者だけ。メンバーは閲覧のみ／編集ありで出るボタンが違う。
- **見積入力の固定の高さ**（上のツールバー 48px・下の合計バー・スマホの下固定 56px など）に、他の部品の位置計算がつながっています。**固定する部品を増やす案は、合計の高さも書いてください。**
- 全体リマークの「取っ手バー」と、右下の部品の位置は、CSS 変数（`--rms-bar`）でお互いに避け合っています。右下の部品を減らす案なら、この仕組みが**簡単になる**かも書いてください。
- 見積入力は旧画面と新画面の両方が残っています。案は**両方で成り立つ**か、**新画面だけ**かを書いてください。
