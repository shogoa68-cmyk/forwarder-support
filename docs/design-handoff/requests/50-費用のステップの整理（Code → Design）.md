## 1. ごちゃごちゃに見える原因（Code の見立て）
1. **同じ金額が何度も出る**：サブコン見出し・パターン見出し・パターン小計・サブコン小計の 4 か所に同じ売・仕入・粗利（パターンが 1 つのサブコンでは 4 回とも同じ数字）。さらに表の合計行と画面下の合計バーも同じ。
2. **明細 1 行が背が高い**：単価が「仕入・乗せ幅・売」の 3 段で、7 行で画面 2 枚分。サブコン名・パターン名を見出しと**各行の欄**の両方に出している。
3. **列が多く、狭い**：通貨が「仕・売」の 2 つ、小計・利益の列に「≈ 円」「粗利率」が詰まる。項目名の下の備考欄が常に見える。
4. **操作の入口が散らばる**：上の操作の行・操作バー・見出しの［＋ 明細を追加］［⋯］・小計行の［＋ 行追加］・行の［⋯］・行の［その他 ▾］・チェックの一括操作バー。どこで何をするか覚えにくい。
5. 換算レート・［＝ 小計行］・［末尾に追加 ▾］が常に上にあるが、毎回は使わない。
6. 「（カテゴリなし）」「⠿」などの補助の文字・記号が見出しに残る。
7. スマホ：一覧と編集シートは動くが、見出し（Design 43）の形がまだスマホに入っていない。

## 2. 案（Code の考え・参考）
- **A：1 行＝1 段（表計算の行のように）**：明細は「項目名｜数量×単位｜仕入（通貨つき）｜乗せ幅｜売（＝自動）｜小計｜粗利」の 1 段（高さ 40px 前後）。備考・サブコン欄・パターン欄・％・MIN などは、行を押す／［⋯］で開く「行の詳細」（右の列か、行の下に開く）へ。金額の要約は**見出しにだけ**出し、小計の行は「パターンが 2 つ以上のサブコン」だけ。換算レート・小計行・追加位置は［⋯］の中へ。
- **B：今の 3 段のまま、重複だけ減らす**：小計の行をやめて見出しの金額だけにする・サブコン欄／パターン欄を行から隠す・換算レートを畳む。
- **C：①②③⑤とそろえて「左＝表・右＝選んだ行の詳細」**：右の列（280px〜）に、選んだ明細の全項目（備考・％・MIN・幅・貿易条件・表示条件・状態）を出す。表は 1 段で軽くする。
- Code のおすすめは **A**（C は表の横幅が足りなくなる心配があるため。A の「行の詳細」の出し方として C の右の列も選べる）。

## 3. 決めてほしいこと
1. A／B／C（または別案）。
2. 明細 1 行の列と高さ（仕入・乗せ幅・売の見せ方、通貨の置き場所、小計・粗利の見せ方、外貨の ≈ 円）。
3. 行に出さない項目（備考・サブコン欄・パターン欄・カテゴリ・課税）の置き場所と開き方。
4. 小計の行の要否（見出しの金額と重なる件）・合計の行と画面下の合計バーの重なり。
5. 操作の入口の整理（サブコンの追加・明細の追加・行の複製／削除・一括操作・小計行・追加位置・チャージ・換算レート）。
6. 行の［その他 ▾］（13 個の設定）の置き場所（Design 36 の分類はそのまま使う）。
7. 状態（要調査・見積書に出さない・入力完了・適用期間外・表示条件外）の見せ方。
8. スマホの組み方（一覧・編集シート・見出し）。

## 4. 制約（いつもどおり）
- 保存データ・id・onclick は変えない（表示の出し分けと要素の移動だけ）。旧画面はそのまま。
- 明細の行は表（`<tr>`）のまま（並べ替え・キーボードでの移動・貼り付け・Excel/PDF への出力がこの行を読むため）。仮想の行（見出し・小計）は表示専用。
- 3 テーマ（Industry／現行／Quiet）で崩れないこと。文字は 12／13／14／16／18px。欄の高さは PC 36px／スマホ 44px。スマホはタップ 44px 以上。
- 案（パターン）のタブ（上部ツールバー）・入力完了の記録・％／MIN／幅などの計算は変えない。
