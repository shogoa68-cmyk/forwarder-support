# 出力ボタン（保存・プレビュー・PDF）の強さと並び：案1（Design → Code）

2026-11-18。要望37への回答です。**右上のままで良い／4点の直しも方向は合っている**。そのうえで強さと並びは**案1（主ボタンは右端の1つだけ）で確定**。参考：`reference/Output Buttons Options.dc.html`（案1 タブ）。※参照ファイルは描画できない前提で、必要な数字はすべてこの文書に書きます。

## 1. 確認への答え（5つ）
1. **主ボタンは1つ**：はい。右端の1つだけ濃色。PDF・プレビューは白地＋枠の副ボタン。
2. **［✏️ 編集を始める］**：閲覧中は**濃色の主**にする（白地＋青枠だと「保存」と並んで迷う）。編集中は薄くせず**消す**。
3. **橙の点**：12pxのままでよい。**白い縁2px**を付ける。`title`「未保存の変更があります」と⑤の枠の一文で補う。
4. **⑤の「出力する」の枠**：薄い青の枠・見出し・説明1行はそのままでよい。文言と並びを下のとおり直す。
5. **プレビューを合計バーのそばへ**：**見送りでよい**（固定の帯が増える。スマホの下は合計バー＋ボタン帯で既に2段＝約104px）。

## 2. PC：上のバー（右側）
- 並び（左→右）：［⋯］［✏️ 編集を始める（閲覧中だけ）］［📋 プレビュー］［📄 PDF 出力］［💾 保存］。
- **強さ**：副ボタン＝白地・枠 1px #98a2b3・文字 #101828。主ボタン＝濃色 #101828・白文字。高さ 38px・角丸 6px・13px太字。
- **状態ごと**：
| 状態 | ［✏️ 編集を始める］ | ［📋 プレビュー］［📄 PDF 出力］ | ［💾 保存］ |
|---|---|---|---|
| 閲覧中 | **出す（濃色・主）** | 副（押せる） | 薄い副（押せない・不透明度 .4） |
| 編集中・未保存 | 出さない | 副 | **濃色の主**＋橙の点 |
| 編集中・保存済み | 出さない | 副 | 濃色の主（点なし） |
| 他の人が編集中／閲覧のみ権限 | 出さない | 副 | ［🔒 閲覧のみ］（薄い副・押せない） |
- **保存の位置は動かさない**（右端固定）。［編集を始める］は保存の左に出入りする。
- **橙の点**：保存ボタンの右上・直径12px・色 #f79009・**白い縁 2px**。`title`＝「未保存の変更があります」。

## 3. ステップ⑤の「出力する」の枠
- 枠：薄い青（背景 #eef3fb・枠 1px #bcd0ee・角丸12px・余白 14px 16px）。見出し「出力する」（18px 太字）。
- 説明：「できあがったら、ここから御見積書を出せます。」（**「（上のバーのボタンと同じです）」は外す**）。
- **未保存のときだけ**、説明の下に橙の一文（12px 太字・#b54708）：「● 未保存の変更があります。先に［💾 保存］をおすすめします。」
- ボタンは上のバーと**同じ順・同じ強さ**：［📋 プレビュー］［📄 PDF 出力］（副）／［💾 保存］（主）。閲覧中は［✏️ 編集を始める］（主）を保存の左に。高さ 44px。
- **スマホ（〜600px）**：［プレビュー］［PDF 出力］を**横2つ**（各 44px）、その下に［保存］を**全幅**。閲覧中は［編集を始める］を全幅（保存はその下に薄く）。

## 4. スマホ：下の固定（56px）
- 並び：［📋 プレビュー］［📄 PDF 出力］［💾 保存］の3等分（保存はやや広く）。保存だけ濃色。
- 閲覧中は右端が［✏️ 編集を始める］（濃色）。［💾 保存］は出さなくてよい（スマホは幅が足りないため）。他の人が編集中は右端［🔒 閲覧のみ］（薄い・押せない）。
- 橙の点：右端ボタンの右上に同じ12px・白縁。
- 高さ：合計バー 48px＋ボタン帯 56px。**固定の高さは増やさない**。

## 5. 残っている提案への答え（案4）
- **スマホで❓が入力欄に重なる件**：**入力欄・テキストエリアにフォーカスがある間だけ❓を隠す**（フォーカスを外すと戻る）。サイズ・薄さの調整より確実。
- ボタン名・［その他 ▾］の畳み方は、今回は触れない（Design 36 の案Pで説明を付けたので、様子を見る）。

## 6. 制約への対応
- 機能は消さない。既存の DOM・id・onclick を残し、上のバー・⑤の枠・スマホの下は**同じ処理を呼ぶだけ**（今のまま）。
- 3テーマ：色は共通トークン経由（濃色＝`--text`相当／橙＝警告色トークン）。文字は 12／13／14／16／18px のみ。タップは44px以上（スマホ）。
- 印刷では出さない。保存データは増やさない。旧画面は対象外（新画面のみ）。

## 7. コードへの確認
1. 閲覧中に［💾 保存］を薄く出したまま、［✏️ 編集を始める］を保存の左に出し入れしても、上のバーの `top` 計算・固定の高さに影響しないか（ボタンの出入りだけのはず）。
2. 順番を［プレビュー］［PDF］［保存］に入れ替えても、`#quoteActionDock` の既存 id・onclick が壊れないか（並びは CSS の `order` で対応できるか）。
3. 入力欄フォーカス中の❓非表示は、`focusin`／`focusout` で足せるか（見積入力のスマホだけでよい）。
4. 橙の点の白い縁（2px）は、Quiet テーマでも見えるか（背景が白に近いテーマでは縁が目立たないので問題なし／濃い背景では縁が効く）。

## 8. 割り切り
- 閲覧中と編集中で、主ボタンの中身が変わる（閲覧中＝編集を始める／編集中＝保存）。ただし**別のボタン**で、保存の位置は動かさないので、押し間違いは減るはず。
- PDF は副ボタンで目立たないが、⑤の枠とバーの両方にあるので探せる。
