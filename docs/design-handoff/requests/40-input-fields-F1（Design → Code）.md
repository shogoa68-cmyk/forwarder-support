# 40 入力欄の大きさと並び：決定（Design → Code）

要望40への回答です。画面案は reference/Input Fields Options.dc.html（F1 を選んで見てください）。

## 決定
1. **高さ**：PC 36px／スマホ 44px。ボタン（自動採番・変更▾・％関税率）も同じ高さで欄の横に付ける。③の44px（貨物名・HS）も36pxに。セレクト・日付も36px。
2. **右の空き**：**F1＝2列の格子**。本文幅（1000px）を左6列＋右6列（gap 12px）に分け、各行の左右の端をそろえる。案件名・貨物名は12列（全幅）。幅は中身の長さのヒントにしない（割り切り）。
3. **①の並び**：1行目［お客様名称｜ご担当者］→ 2行目［案件名（全幅）］→ 3行目［見積もり番号（自動）｜依頼受信日（自動）］→ 4行目［発行日｜有効期限］。自動の欄は「自動」の小ラベルを付ける。見積もり番号は表示だけ（自動）で、直すときは［変更］で欄を開く。
4. **②の国**：国を港の左（国170px→港340px、隣り合わせ）。港名から国を自動で入れる動きはそのまま。国が空でも港を先に入れてよい。
5. **③のモード別**：やる。FCL＝コンテナ本数を先、LCL・航空＝荷姿（個数・寸法・重さ）を先に出し、もう一方は［詳細 ▾］の奥へ。
6. **⑤の並び**：①見出し→②定型文タブとボタン→③文章の欄→④品物別リマーク・常時付記・画像を添付。「0文字・クリア」は欄の右下にまとめる。

## そのほか
- 左右の端：入力欄・［戻る］［次へ］・⑤の「出力する」の枠を本文幅の左右にそろえる。［戻る］は左端（216px）へ。
- 見出しの二重：「🗂 管理番号入力」は消してよい。「？」ヘルプは「1 基本」の右へ。
- ①：ご担当者の例文は「例）山田」だけ（説明は「？」へ）。「＋ 関連番号・メール件名を追加」は［その他の情報］の中へ。［📝 社内メモ］は案件名の見出しの右へ。
- ②：貿易条件は上の帯を残し、下の「インコタームズ EXW ✎」は消す（編集は帯の✎）。
- ③：「クリア」は貨物情報の見出しの右端へ、名前は「貨物情報をクリア」。
