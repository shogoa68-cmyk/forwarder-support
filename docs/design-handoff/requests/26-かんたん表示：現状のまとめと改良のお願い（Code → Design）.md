# かんたん表示 — 現状のまとめと、改良のお願い（Code → Design）

2026-11-15。「かんたん表示」に改良を加えたいので、現状を渡します。画像は `26-assets/`（偽データ・Industry・PC 幅 1400px）。**詳細表示（いまの標準）を磨いたあと、かんたん表示は置いていかれています。** 詳細で決まった形（案件カードの C-3・上部の整理・絞り込みの F3 など）が、かんたん側には入っていません。

## 0. 先に決まったこと（前提）
- **スマホ幅（〜600px）は常に「詳細表示」**（かんたん表示は使わない・切替ボタンも出さない）。実際に見て、スマホは詳細のほうがすっきりしていたため。→ **かんたん表示の対象は PC・タブレット幅（601px〜）**。
- 切替は、ダッシュボードの［⋯］とツールバー「⋯」の「かんたん／詳細」。保存は端末（`fwd.uiMode`）。**既定はまだ「詳細」**（`UI_MODE_DEFAULT`）。検証後に「かんたん」へ変える予定。
- 仕組み：`<html class="mode-simple">` のときだけ `css/simple-mode.css` が効く。**隠す項目は DOM に残す**（保存・計算は継続）。上級機能を使っている案件は、自動でその項目を表示する。

## 1. 今のかんたん表示（見たまま）
**ダッシュボード**（`dashboard-simple-pc.png`）
- 上：見出し＋［＋ 新しい見積を作る］・［⋯］。ステータスのチップ（全体／作業中／提示済み／受注／その他）・道具の行（範囲・検索「お客様名・案件名で検索」・タグ・絞り込み・ランキング・表示）。
- その下に点線の「＋ 新しい見積を作る」カード（お客様名とご担当者を入れるところから始めます）。
- **案件カードは「旧い構造」のまま**：1 行目＝状態▾・番号・案件名・🚨緊急、2 行目＝お客様名（大）、その下に取引形態の札・「X社・山田 様」・「🔔 料金フォロー」、右下に［開く］［⋯］、いちばん下に「💬 申し送り（まだありません）」。緊急の案件はカード全体が薄い赤。
- 詳細表示のカード（左のお客様ブロック・案件名ヘッダー・進捗の帯・作業者の丸アイコン・枠と影）は**入っていません**。

**見積入力画面**（`editor-simple-pc-top.png`／`editor-simple-pc-mid.png`）
- 上部に「①条件 ②貨物 ③費用 ④出力」の道しるべ（スクロールに付いてくる）と、ひと言の案内。
- 任意の項目は畳む（「必要なときだけ開く」・作業範囲など）。ツールバーは「ダッシュボードに戻る」と「⋯」だけ。
- ※画像は偽データで案件が空のため、表（費用）は小さく出ています。

## 2. 気になっている所（私の目視・漏れあり）
1. **カードが詳細と別物**：同じ案件なのに、モードで見た目の作りが違う。かんたん側の目的（情報を減らして迷わせない）に合わせた「かんたん専用のカード」を作り直したい。
2. **上部の道具の行が多い**：かんたんでも［範囲・タグ・絞り込み・ランキング・表示］が全部出ている（詳細と同じ）。かんたんなら「検索＋状態」だけにして、残りは［⋯］の奥でもよいのでは。
3. **カードの情報の優先順位**：かんたんで最低限ほしいのは、案件名・お客様・状態・次にやること（開く）くらいでは。番号・料金フォロー・申し送りは出し入れの案がほしい。
4. **見積入力の道しるべ**：①〜④は進捗が分からない（どこまで入力したか）。詳細のカードの「進捗の帯」のような見せ方を、入力画面の道しるべにも使えるか。
5. **「詳しく絞り込む」**（かんたんだけの折りたたみ）は、新しい上部では隠している（絞り込みは［🔎 絞り込み］に集約済み）。かんたんの絞り込みの出し方の案がほしい。

## 3. お願い（Design）
- **かんたん表示の目的と対象ユーザーをもう一度そろえたい**：誰が・どの場面で使うか（IT に不慣れな新規ユーザー／営業が出先で確認する、など）。それで「減らす項目」が決まります。
- ダッシュボード（上部・カード・空の状態）と、見積入力（道しるべ・畳み方・出力への導線）の**かんたん専用の案**。詳細で決めたトークン・色（取引形態の色・状態の色）は共通で使えます。
- **PC・タブレット幅だけ**で考えてよい（スマホは詳細）。

## 4. コード側の事情（知っておいてほしいこと）
- 詳細と同じデータ・同じ関数を使う（隠す／並べ替えるだけ。保存形式は変えない）。**かんたん専用に項目を足すのは難しい**（足せるのは見た目と出し入れ）。
- カードの構造は `cloud.js _cloudCardHtml` が 1 つで、かんたんは CSS で出し分けている。かんたん専用のカードを作る場合は、`sd`（かんたん）のときだけ別の HTML を作る形になる。
- 試験：`scripts/design-tests/*-test.js` の多くは詳細表示で動く。かんたんは `simple-*` 系の試験で確認。
