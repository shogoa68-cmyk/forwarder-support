# 見積入力画面の上部（ツールバー＋ステップ）のデザイン改善のお願い（Code → Design）

2026-11-17。見積入力（新画面＝editor-v2）の**いちばん上の 3 段**（カテゴリ → ツールバー → ステップ 5 つ）だけに絞った依頼です。**3 案くらい方向の違う案**をお願いします（選んだ案をコードに落とします）。
画像：`sample-30-editor-top.webp`（実画面・PC 幅 2000px・Industry・閲覧モード・数量パターン 3 つ）。関連：要望 28（見積入力の新デザイン・PC 案B ステップ式）。

## 1. いまの構成（上から）
1. **カテゴリ**：BOOKMARK／見積／統計／マスター管理／サイバーポート／その他 ▾（今回は対象外・触らない）
2. **ツールバー**（`#saveToolbar`・1 行）左→右：
   - ［ダッシュボードに戻る］
   - 題名「案件番号 / 案件名」（例：99-261109-004 / テストデータ）＋ 状態チップ（保留）
   - 作業状態の札（閲覧モードのとき「閲覧モード – 編集するには『✏️ 編集』」／編集中は「編集中」）
   - **数量パターンのチップ**（FCL案／LCL案／AIR案…。2 つ以上あるときだけ。編集中のパターンは濃く）＋「⚠ 要確認 N 行」
   - ［⋯］メニュー（元に戻す・やり直す・メール取込・自由入力を保管・サブコン依頼メール・社内メモ・常に前面・使い方）
   - 出力・保存ボタン：［PDF出力］［プレビュー］［✏️ 編集／💾 保存］（閲覧中は「編集」）
3. **ステップ 5 つ**（カード 1 行）：① 基本（管理番号・お客様・担当者・案件名）② ルート（貿易条件・輸送モード・幹線）③ 貨物・物量 ④ 費用（見積テーブル）⑤ リマーク・出力。各カードに「✓（入力済み）／番号」＋見出し＋**1 行の要約**（例：「KAWASAKI→SHANGHAI」「2行 / 売 37,000」「リマークあり」）。押すとそのセクションだけ表示。選択中は濃い枠。
4. （この下に本文。下には常時の合計バー・［← 戻る］［次へ］がある＝今回は対象外）

## 2. 困っていること（見たまま・使っている側の声）
- **縦の高さを 3 段（カテゴリ＋ツールバー＋ステップ）で使いすぎ**。ステップのカードは約 80px あり、費用の表を見ながら作業するときに本文が狭い。スクロール時の固定（sticky）は何段まで残すべきか。
- **ツールバーが窮屈**：数量パターンのチップが右端で**切れて見える**（「CL案」「AIR」が欠ける）。パターンが 4 つ以上になると読めない。題名・状態・作業状態の札・パターン・［⋯］・出力 3 ボタンが 1 行に詰まっている。
- **作業状態の札（閲覧モード…）が長く**、題名との位置関係が分かりにくい。「編集中」の札と保存ボタンの意味も重なる。
- **出力ボタン 3 つの重さが同じ**：普段押すのは［保存／編集］と［プレビュー］、PDF は最後。主操作が 1 つに見えない。
- **ステップのカードは情報が多いのに押しにくい**：✓ と番号の丸・見出し・要約の 3 要素が同じ強さ。「いまどこ／どこが未入力か」が一目で分からない（✓ は“入力済み”だが、順番通りに進む必要は無い）。
- 3 つのテーマ（現行／Industry／Quiet）で崩れないこと。

## 3. お願いしたいこと
- **3 案くらい**（紙芝居でも HTML でも可）。観点の例：
  - ステップを**ツールバーに統合**して 1 段にする（例：左に題名、中央に「基本 › ルート › 貨物 › 費用 › 出力」の細いタブ／パンくず、右に出力）。要約は**ホバー／選択中だけ**出す、など
  - ステップは残すが**背の低いタブ**（要約は選択中のみ）にする
  - 数量パターンの置き場所（ツールバー／費用ステップの中／下の合計バー）と、**多いとき**の表示（横スクロール・「他 N」・セレクト）
  - 作業状態（閲覧／編集中／ロック）の見せ方（札を 1 つに・色・題名の隣）
  - 出力ボタンの**優先順位**（主＝保存／編集、副＝プレビュー、PDF は「⋯」か分割ボタン、等）。閲覧モードと編集モードで何を出すか
  - 未入力の見せ方（必須の欠けだけ小さな印にする等）
- **優先して見たい状態**：①閲覧モード（画像）②編集中 ③数量パターンが 0／1／5 つ ④長い案件名・長いお客様名 ⑤スマホ幅（〜600px・いまは 5 分割のステップが別にある）。
- 各案の**良い点・割り切り**を一言ください。

## 4. 守ってほしい制約
- **機能は消さない**（隠す・畳む・移すのは可）。既存の DOM・`id`・`onclick` を残して CSS／薄い表示層で組み替える方針（現状もそうしています）。保存データは変えない。
- ステップは「押すとそのセクションだけ表示」＋［← 戻る］［次へ：○○ →］の挙動を維持（順番通りに進めなくてよい）。必須が未入力でも止めない。
- 固定（sticky）の高さの合計：下に続く操作バー等の `top` 計算に影響するので、**固定の合計高さ**（いまはカテゴリ＋ツールバー 44px＋ステップ）を明記してほしい。
- 3 テーマ（現行／Industry（既定）／Quiet）の共通トークンで色を指定。文字は 12／13／14／16／18px（`--text-xs/sm/base/lg/xl`・スマホは一段大きい）。タップ領域はスマホで 44px。
- 管理者／メンバー／閲覧のみ、閲覧モード（他の人が編集中でロックされている場合を含む）で出るボタンが違う。
- 旧画面（editor-v1）は別に残してあるので、案は**新画面のみ**が対象。
