## 4. 未解決・解決済み
- 切り替えの既定：**未解決が1件以上なら「未解決」、0件なら「すべて」**。
- 「すべて」のときは、未解決が先。解決済みは「✓ 解決済み N 件 ▸」（36px・点線の枠）で畳み、押すと開く。
- 並びは発生日の新しい順（同じグループの中で）。
- 件数は切り替えの中に出す（今の「未解決 1件／全 3件」の赤い文字は消す）。

## 5. 入力欄（記録する／編集）
題「＋ 事例を記録」（16px 太字）。すべての欄の**上に見出し**（12px 太字）。任意の欄は見出しの横に灰の「任意」、必須は赤の「必須」。

| 3 | **見出し（必須）** | 幅いっぱい・36px |

- 例文（placeholder）は短く（「例）海上運賃のみ5%で合意した」など）。見出しがあるので例文に欄の名前は入れない。

- 見出しが空のまま［記録する］を押したら、欄を赤枠にして「見出しを入れてください」。

## 6. スマホ（〜600px）

- ［＋ 事例を記録］は画面の下に固定（帯 56px・ボタン 44px・横幅いっぱい）。
- 入力は全画面のシート。［記録する］はシートの下に固定（キーボードが出ても押せる）。欄・チップは 44px、文字はトークンどおり一段大きく。
- 切り替え［未解決｜解決済み｜すべて］は上に固定せず、一覧の頭に置く。
