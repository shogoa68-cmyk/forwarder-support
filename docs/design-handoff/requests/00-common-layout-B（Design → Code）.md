# 46〜48 共通：ステップの「左右2列」の決まり（Design → Code）

①基本・②ルート・③貨物・物量・⑤リマーク・出力は、すべて**案B（左＝入れるもの・右＝この案の条件／添えるもの）**にそろえます（④費用は対象外・今のまま）。各ステップの中身は 46／47／48 のメモ。

## 1. 組み立て（本文が 1100px 以上のとき）
- 本文の中を `grid-template-columns: 1fr 280px; gap: 16px`。
- 右の列：左に 1px の線（--border）＋左の余白 16px。見出し（13px 太字・灰）＋**1行ずつの行**。
- 右の列は `position: sticky; top:（ツールバー48px＋8px）`。縦に長いステップでも右の列は見えたまま。
- 本文の見出し：「N 名前」（18px 太字）＋何をする場所かの1行（12px 灰）。値（お客様名・ルートなど）は出さない（上のバーと左のステップの要約にあるため）。

## 2. 右の列の「行」（共通の部品）
- 高さ 40px（スマホ 44px）・下に 1px の線。
- 左に項目名（12px 灰・幅 78px）、中に値（13px・1行で…省略）、右に操作（▾ 選ぶ／＋ 追加／› 開く／スイッチ）。
- 値が無いときは灰の「なし」または「使わない」。
- 押すと**その行の下に入力欄が開く**（36px の欄・Design 40）。開いた行は背景 #fbfcfd。もう一度押すか、ほかの行を押すと閉じる。
- 実装：既存の欄（id そのまま）を右の列の中へ移し、閉じているときは表示だけ隠す。行の値は欄の値から作る。

## 3. 1100px 未満・スマホ
- 1100px 未満：右の列を左の列の下へ（1列）。sticky は外す。
- スマホ（〜600px）：同じく1列。行は 44px。ステップのボタンは、選んでいるものだけ名前・ほかは番号だけ（名前の切れを防ぐ）。❓ は入力欄の右端に掛からない位置へ。
- ［次へ］は「次へ →」だけの短い文言でもよい（1行に収める）。

## 4. 消すもの（全ステップ共通）
- 要約の帯（Design 40）：右の列が代わりになるので、新画面では出さない。
- 小見出し「まず入れるもの」「日付」「必要なときだけ開く」などの細かい見出し、点線の［＋ 〜（任意）］の帯。
- 欄名の横の「?」：全体の ❓（用語）に任せる。
- 「自動」「標準」の札：値の後ろの灰の小さな文字「（自動）」「（標準）」へ。

## 5. 制約
保存データ・id・onclick は変えない（表示の出し分けと要素の移動だけ）。旧画面はそのまま。3テーマ。文字 12/13/14/16/18px。欄 36px／スマホ 44px。タップ 44px。
