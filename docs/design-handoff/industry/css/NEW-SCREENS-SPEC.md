## A-1. 見出しを減らす
- 名前付きと設定なしの見分け：**設定なしは灰色＋灰の左線**、文言は「パターンなし」（🔖と括弧を外す）。名前付きは水色＋濃い左線のまま。
- **省略**：サブコンのパターンが設定なし1つだけなら、パターン見出しを隠す（`is-pt-solo`）。パターンのカテゴリが1つだけなら、カテゴリ見出しを隠し、名前をパターン見出しの右に出す（`is-cat-solo`、`.pt-cat-inline`）。どちらも**JS が class を付け、CSS で非表示（DOM は残す）**。
- カテゴリ見出しは 26px・淡い灰・「カテゴリ」の語なし。
- **小計行**：売値合計を大きく、仕入・粗利率を小さく。客先表示名・リマーク（サブコン別／パターン別）の入力欄は「注記 ▾」に畳む（`.st-notes` で包み、`is-notes-open`）。値があるとき、ボタンに ● （`.has-value`）。

## A-2. ミニマム
- オフ／オン・未入力／適用中の3状態（案を参照）。オン・未入力は **ボタンに「未入力」** と書く（`.min-mode-btn.is-on.is-empty`）。
- 入力欄は「その他 ▾」の中に **「最低料金（MIN）：仕入 [ ] 売値 [ ] USD」** と1行で（`.min-group`）。
- 適用中は、売値の欄の**左に「Min. 28.00 適用」**を重ね（`.stk-sell .min-note`、`tr[data-min-applied="1"]`）、小計の下に「MIN 適用」。0.1×100≠28 の理由が行で分かる。
