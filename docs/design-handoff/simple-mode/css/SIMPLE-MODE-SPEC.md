# 「かんたん表示」仕様（Claude Design → code）

デザイン案：`Simple Mode.dc.html`　／　CSS：`css/simple-mode-industry.css`

## 切替の仕組み
- 状態：`<html class="mode-simple">` が付いていれば「かんたん」。外せば「詳細」。**既定はかんたん**。
- 保存：localStorage に `fwd.uiMode = "simple" | "detail"`。初回は simple。
- スイッチ：見積入力＝上部の固定ツールバー右端／ダッシュボード＝タイトル行の右。2択のセグメント「かんたん表示 | 詳細表示」（常に両方見える）。
- 隠した欄も DOM に残す（`display:none`）。`data-tier="req"` は絶対に隠さない（CSS 側でも `!important` を付けない）。

## 区分の付け方（HTML）
`data-tier="req|opt|adv"` を各ブロックに付ける。CSS だけでは付けられないので **HTML 変更が必要**。
- `opt` のブロックは `<details data-tier="opt"><summary>…</summary>…</details>` に変更（かんたん＝閉じる、詳細＝開く。JS でモード切替時に `open` を付け外し）。
- 「必須／任意」の印：`<span class="tier-badge req">必須</span>` / `<span class="tier-badge opt">任意</span>`。

### 手順の道しるべ（HTML変更あり）
- 既存の進捗バー `qp-*` を、4段「① 条件 → ② 貨物 → ③ 費用 → ④ 出力」にし、現在の段に `.is-current`。
- 直下に「いまは ①。次は …」の一文（`.qp-hint`）を追加。現在地は入力状況から JS で判定。

### 固定ツールバー・右レール
- アイコンだけのボタンに文字ラベルを追加（`.rail-label` を span で追加）。文言：元に戻す／やり直す／その他／ジャンプ／金額を見る／申し送り／その他のツール。
- 普段使わないものに `.toolbar-extra` を付け、かんたんでは「その他 ⋯」メニュー（`.toolbar-more`、新規）の中に出す。**JS：メニュー開閉と、中の項目が元ボタンの `onclick` を呼ぶこと**。

| 項目 | 区分 | かんたん | 詳細 |

### カードの構造（HTML変更あり）
1. 左：状態タグ → 案件名（18px 太字）→ お客様・担当 → ルート → 進捗＋更新日。
2. 右：申し送りバッジ（`.dash-memo-badge`）＋ **開く**（primary）＋ 「⋯」（`.dash-menu`）。
3. 「⋯」内：プレビュー／PDFを出力／コピーして新規作成／（区切り）削除…（`.dash-menu-danger`、確認ダイアログは従来どおり）。
4. 申し送りの本文・入力欄は `.dash-memo-body`（既定で閉じる）。バッジで開閉。

### ログイン前
- 2枚のカードを並べる：「ログインして使う（おすすめ）」＝チームの共有フォルダ／どのパソコンでも続き／申し送りや集計が使える。「ログインせずに使う」＝保存はこのパソコンだけ／共有されない／ブラウザのデータを消すと見積も消える。
- 文言のみの変更＋レイアウト（HTML変更あり）。

## 言葉の置き換え
読込→開く／編集画面へ→作業中の見積に戻る／ブラウザ保存→この端末に保存（＋「チームには共有されません」）／ログインせず新規作成（このブラウザ内のみ）→ログインせずに使う（保存はこのパソコンだけ）／検索ボックス→お客様名・案件名で検索（対象の詳細は補足に）／↶ ↷ ⋯→元に戻す／やり直す／その他。

## CSS だけでできること／できないこと
- CSS のみ：区分に応じた表示切替（`data-tier` が付いていれば）、印の見た目、道しるべの見た目、カードの文字サイズ、進捗の非ボタン化。
- HTML/JS が必要：`data-tier` の付与、`<details>` 化、道しるべの一文、「⋯」メニュー（ツールバー・カード）、申し送りの畳み、モード切替スイッチと保存、文言置き換え、ログイン前の2カード化。
