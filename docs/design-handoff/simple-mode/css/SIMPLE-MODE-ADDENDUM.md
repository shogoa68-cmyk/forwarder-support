# かんたん表示 追加回答（Design → code）

デザイン案：`Simple Mode Extras.dc.html`

## 0. 「案件名」
- **案件名 ＝ ②メモ1行目（`.cloud-card-memo`）**。カードの見出し（18px 太字）。
- REF#（`.cloud-card-name`）は状態タグの隣に 12px の補助。お客様名（`.cloud-kv-cust`）は 13px で2行目。
- メモが空：見出しは「ルート」→ ルートも空なら REF#。「（無題）」とは出さない。

## 1. 上級機能を使っている案件
- かんたんで開いたとき、隠した adv 項目に**値が入っている場合だけ**、(a) 画面上部の帯「一部を隠しています／この見積は『往復』『複数航路』『FCL/LCL比較』を使っています。入力内容は保存・出力に含まれます／[詳細表示で全部見る]」、(b) 該当セクションに点線チップ「ほかに N 件：…」を出す。値がなければ何も出さない。
- 帯のボタンは詳細表示への切替（localStorage 更新と同じ処理）。
- 実装：JS が adv 項目の値を走査して件数と名称を作る。CSS だけでは不可。

## 2. 初回の案内
- 切替スイッチを指す吹き出し（幅 340px、blueprint 枠、影 `--shadow-md`）。画面は暗くしない。
- 文言：「画面が新しくなりました／よく使う項目だけを表示しています。すべての機能は、右上の『詳細表示』に切り替えるといつでも使えます。」
- ボタン：「閉じる」「詳細表示を見てみる」。どちらでも1回で非表示（`fwd.uiHintSeen=1`）。

## 3. リスト表示（かんたん）
- 列：状態｜案件名（＋小さく REF#・申し送り件数）｜お客様｜ルート｜更新日｜開く｜⋯。計7列。
- 進捗・担当・タグ・経過日数は詳細表示でだけ列を追加（`.qpd-rows-head` の列定義を `.mode-simple` で切替）。
- 行 hover は淡い鋼青。「開く」は primary、小さめ（高さ auto・padding 4px 12px）。

## 4. 「⋯」メニュー
- トリガー：36px 角、`aria-label="その他の操作"`、焦点は 2px アクセント枠＋offset 2px。
- 項目の高さ 40px。区切り線は「削除」の上だけ墨色 1px、他は薄い罫線。影 `--shadow-md`、角 0。
- 並び：プレビュー／PDF を出力／コピーして新規作成／（区切り）削除…（赤字 `#b0392e`、600）。
- 押した行（hover・矢印キー）：淡い鋼青の背景＋左に 3px の鋼青線。
- 削除不可（`.is-locked`）：薄い灰色のまま残し、理由を1行添える（「○○さんが作業中のため削除できません」）。
- ツールバー「その他 ⋯」は既存 `.tb-menu-panel`／`.tb-menu-item` を流用。小見出し「取り込み・送る」「設定」でグループ化。
- キー操作：開いたら最初の項目に焦点、↑↓で移動、Esc／外側クリックで閉じて「⋯」に焦点を戻す。

## 5. モバイル幅の切替スイッチ
- ヘッダーの直下に全幅の2分割ボタン（高さ 48px 以上）。ラベルは「かんたん」「詳細」。固定にはしない。
- 見積入力では固定ツールバーが狭いため、ツールバーの外、画面見出しの下に置く。

## 色の変数名（3章7への回答）
- `--color-*` は Industry 側の名前。実アプリでは、フォールバックの16進値をそのまま使ってよい。tokens.css の変数名（`--accent` 等）に置き換えて問題ない。
