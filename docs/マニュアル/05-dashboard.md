`💼 見積を作る` を押して最初に出る画面が、チームの見積の一覧（ダッシュボード）です。

## カードの見方

- 左：お客様の名前とご担当者。色の帯は取引の形（荷主＝青・同業者＝橙 など）。
- 右上：案件名と、5 つの印（条件・貨物・仕入・利益・出力）。緑はできている所です。
- 下：作った人・更新した人。
- `読込`：その案件を開きます。`⋯`：プレビュー・コピー・削除・タグの追加など。

## 探す・絞り込む

- 上のチップ（全体・作業中・提示済み・受注・その他）でステータスを選びます。
- 検索欄に、お客様名・案件名・見積番号を入れます。
- `🏷 タグ`：タグで絞り込み（複数選べます）。`🔎 絞り込み`：輸送モード・積み港 → 揚げ港・インコタームズ。
- `表示 ▾`：並び順・カード／リストの切り替え。

## 便利な使い方

- `📋 コピー`：過去の案件をまるごと写して新しい見積にします（日付・番号は新しくなります）。
- 関連する案件どうしを「関連付け」でつなげると、カードの「🔗 関連」から行き来できます。

```lesson
id: find-case
title: 案件を探してみる（約 1 分）
open: tab-quote-make
step: #dtChips | 上のチップで、ステータス（作業中・提示済み・受注…）ごとに絞り込めます。
else: - | ログインすると、チームの案件が一覧に並び、ここで絞り込めます。
step: #qpdSearch | ここにお客様名・案件名・見積番号を入れると、その案件だけが出ます。
step: #dtTagBtn | タグで探すときはここ。いくつか選んで「すべて含む／どれか含む」を切り替えられます。
step: #dtFilterBtn | 輸送モードや積み港 → 揚げ港でも絞り込めます。
step: .cloud-card | 1 枚が 1 つの案件です。「読込」で開き、「⋯」でコピーやプレビューができます。
else: - | 案件ができると、ここにカードが並びます。
```
