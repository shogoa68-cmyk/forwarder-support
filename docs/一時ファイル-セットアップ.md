# 📁 一時ファイル置き場 セットアップ手順（管理者向け）

見積を提示するときに添える参考資料（スケジュールなど）を、**案件ごと・置いてから 3 時間だけ**置いておく場所です
（見積入力画面の下の引き出し →「📁 一時ファイル」タブ）。置いたファイルは 3 時間で自動的に消えます（延長はできません）。

## 手順（5 分）

1. Supabase のダッシュボード → **Database → Extensions** で `pg_cron` をオンにする（掃除の自動実行に使う。すでにオンなら不要）。
2. **SQL Editor** で `docs/sql/quote-temp-files.sql` を丸ごと貼り付けて **Run**（何度流しても安全）。
   - 表 `quote_temp_files`・非公開バケット `quote-temp`（1 ファイル 25MB まで）・アクセス制限・10 分ごとの掃除が作られます。
3. アプリで案件を開き、下の引き出しの「📁 一時ファイル」を開いて、小さなファイルを置いてみる。

SQL を実行する前でも、ほかの機能には影響しません（一時ファイルの画面に「サーバー側の準備がまだ」と出るだけです）。

## 仕組み・決まり

- 期限は DB が決めます（置いた時刻 + 3 時間）。画面からは変えられません。**期限が来たファイルは、一覧にも出ず、ダウンロードもできなく
  なります**（掃除を待たない）。実際の削除は 10 分ごとの掃除（`quote_temp_files_purge()`）です。
- 案件ごとに置き、チームメンバーなら誰でも見られます。案件を消すと一緒に消えます。**案件を保存してから**使えます。
- 1 ファイル 25MB・1 案件で 50 ファイル／合計 100MB まで（サーバー側でも強制）。Free プランの保存領域（全体 1GB）への影響は小さいです。
- 社外の人に見せるリンクは作りません（手元でダウンロードして、メールに添付する使い方）。

## 確認・トラブル

- 掃除が動いているか：SQL Editor で `select * from cron.job where jobname = 'purge-quote-temp-files';`
  / 手動で掃除：`select public.quote_temp_files_purge();`
- `pg_cron` を使えない場合：掃除の予約は飛ばされます。期限切れのファイルは見えなくなりますが、実体は残ります
  （手動で上の関数を時々実行してください）。
- SQL の確認：`bash scripts/sql-tests/quote-temp-files-sql-test.sh`（使い捨ての PostgreSQL・27 項目）。
